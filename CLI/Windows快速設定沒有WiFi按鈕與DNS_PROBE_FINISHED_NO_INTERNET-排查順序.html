🧠 自我測驗

是非題

  1. DNS_PROBE_FINISHED_NO_INTERNET 通常代表 DNS 伺服器壞掉了。

    它多半代表底層根本沒連上網，先修連線再談 DNS。

  2. 按「關機」再開機，跟按「重新啟動」對驅動程式的效果是一樣的。

    Windows 快速啟動會把核心狀態寫進休眠檔並還原，連當機的驅動一起還原；只有「重新啟動」會真正重載。

  3. 公共 Wi-Fi 要觸發登入頁時，開一個 HTTPS 網址比較容易成功。

    反過來。HTTPS 有憑證驗證，劫持會被擋下；要開非 HTTPS 的網址（例如 http://neverssl.com）。

  4. WLAN AutoConfig 服務卡住會導致電腦搜尋不到任何 Wi-Fi。

    這個服務負責掃描、選擇與連線無線網路。

填空題

  1. 清除本機 DNS 解析快取的指令是 ipconfig /。

    打在 cmd 或 PowerShell。

  2. Win + R 輸入 .cpl 可以直接開「網路連線」停用或啟用網卡。

    Network Connections Properties Applet。

  3. Win + R 輸入 .msc 可以開「服務」，用來重啟 WLAN AutoConfig。

    Microsoft Management Console 的服務嵌入式管理單元。

  4. PowerShell 一行重啟 Wi-Fi 網卡的指令是 Restart- -Name "Wi-Fi"。

    比在裝置管理員點兩次快得多，需要系統管理員權限。

申論題

  1. 電腦突然連不上網，請說出你的排查順序與每一步在驗證什麼。

    參考方向：由下往上一層一層排除。(1) 實體與驅動層：先看快速設定裡還有沒有 Wi-Fi 按鈕、能不能搜尋到網路。看不到就是網卡或驅動的問題——檢查鍵盤的飛航模式鍵、切換一次飛航模式、ncpa.cpl 停用再啟用網卡、services.msc 重啟 WLAN AutoConfig、裝置管理員停用再啟用，都不行就選「重新啟動」（不要「關機」）。(2) 連線層：搜尋得到也連上了，就看有沒有取得 IP 與閘道（ipconfig /all）。是公共 Wi-Fi 就開一個 http 網址觸發 Captive Portal 登入頁。懷疑設定髒掉就「忘記網路」重連。(3) 名稱解析層：連線正常但網址打不開，先 ping 一個 IP（例如 1.1.1.1）確認出得去，再 ipconfig /flushdns 清快取，還是不行就換 DNS 伺服器測試。(4) 應用層：只有某個網站不行，那是網站或防火牆規則的問題，不是你的網路。(5) 心法：每一步都在回答「問題出在哪一層」，不要一開始就亂試 flushdns。

Windows 快速設定沒有 Wi-Fi 按鈕、搜尋不到網路、DNS_PROBE_FINISHED_NO_INTERNET 的排查順序

[!info]- 🔗 與既有筆記的關聯
(1) 歸進 CLI/ 而不是 command-line/，因為 CLI/ 已經是 Windows／PowerShell 系指令與系統排錯的主資料夾（netsh 防火牆、netstat、磁碟機代號都在那），本篇同屬「用指令救系統」這一族。
(2) 查詢與刪除PID-netstat-taskkill-Stop-Process 與 PowerShell-多指令分隔與netsh防火牆規則 是同一組「網路相關的 Windows 指令」，本篇補的是「連不上網」這個更前面的階段。
(3) Network_and_Gateway_Notes 講的是 DNS 與 gateway 的原理，本篇是那套原理壞掉時的操作手冊，一個是為什麼、一個是怎麼修。

本篇重點 a–l，共 12 個。

重點整理

一、先分清楚是哪一層壞了（a–c）

(a) DNS_PROBE_FINISHED_NO_INTERNET 是 Chrome 的錯誤碼，意思是「瀏覽器要把網域名稱換成 IP 時，DNS 查詢徹底失敗，而且偵測到根本沒有網際網路連線」。它通常不是 DNS 伺服器壞掉，而是底層根本沒連上網。

(b) 三層要分開判斷：

層級 症狀 對應處理
硬體／驅動層 快速設定裡連 Wi-Fi 按鈕都不見了、搜尋不到任何網路 飛航模式切換、重啟網卡、重啟 WLAN AutoConfig
連線層 有連上 Wi-Fi 但顯示無網際網路 忘記網路重連、檢查是否需要登入驗證頁
名稱解析層 連上了但網址打不開 ipconfig /flushdns 清 DNS 快取

(c) Abby 那次是兩個問題疊在一起：快速設定選單開啟的是藍芽（按鈕呈現粉紅色、名稱顯示成手機名稱），同時瀏覽器報 DNS 錯誤——也就是「以為連著網路、其實走的是沒通的藍芽個人熱點」。

二、Wi-Fi 按鈕不見了怎麼救（d–g）

(d) 先檢查實體按鍵：鍵盤 F1~F12 上有沒有無線網路／飛航模式圖示（常見 Fn + F2 或 F12），確認沒有誤觸關閉無線網卡。

(e) 重新啟用 Wi-Fi 網卡：Win + R 輸入 ncpa.cpl 開啟「網路連線」，找到 Wi-Fi，若顯示「已停用」就右鍵「啟用」；若已啟用，先「停用」等 5 秒再「啟用」。

(f) 重啟檔案總管介面：Ctrl + Shift + Esc 開工作管理員，找到「Windows 檔案總管（Windows Explorer）」按「重新啟動」，讓工作列與快速設定選單重新載入。很多時候按鈕不是不見，是那個 UI 元件當掉了。

(g) 檢查快速設定有沒有被誤刪：點開右下角選單，按右下角的筆狀圖示（編輯快速設定），看 Wi-Fi 是不是被移除了，是的話按「新增」加回來。

三、搜尋不到任何網路（h–j）

(h) 切換一次飛航模式：開啟等 5 秒再關閉，強制讓網卡重新搜尋訊號。

(i) 重啟 WLAN AutoConfig 服務：Win + R 輸入 services.msc，找到「WLAN AutoConfig（無線區域網路自動設定）」，右鍵「重新啟動」。這個服務負責掃描、選擇與連線無線網路，它卡住就等於整台電腦看不見任何 Wi-Fi。

(j) 在裝置管理員停用再啟用網卡：Win + X 選「裝置管理員」→ 展開「網路介面卡」→ 找到 Wi-Fi 網卡（通常帶 Intel、Realtek 或 Wi-Fi 6 字樣）→ 右鍵「停用裝置」，等 5 秒再「啟用裝置」。做完還是搜尋不到，就是典型的硬體控制層卡死，直接選「重新啟動」（不要選「關機」）。

[!warning] 為什麼要選「重新啟動」不要選「關機」
Windows 預設開啟「快速啟動（Fast Startup）」，按「關機」其實是把核心狀態寫進 hiberfil.sys 的休眠檔，下次開機直接還原——連驅動程式的當機狀態一起還原。只有「重新啟動」會真正走完整的關閉與重新載入流程。這點 Gemini 沒解釋，但它是「為什麼重開機有用、關機沒用」的真正原因。

四、連上了但網址打不開（k–l）

(k) 忘記網路並重新連線：「設定」→「網路和 Internet」→「Wi-Fi」→「管理已知的網路」，找到該 Wi-Fi 點「忘記」，再重新輸入密碼。

(l) 清 DNS 快取：Win + R 輸入 cmd，然後執行

ipconfig /flushdns

[!tip] 公共 Wi-Fi 的登入驗證頁（Captive Portal）
咖啡廳或公共場所的 Wi-Fi 常需要先在瀏覽器登入。連上之後開新分頁，隨意開一個「非 HTTPS」的網址（例如 http://neverssl.com）就能強制觸發登入頁。
為什麼一定要非 HTTPS？因為 Captive Portal 的做法是把你的 HTTP 請求「劫持」轉址到登入頁；HTTPS 有憑證驗證，劫持會被瀏覽器擋下並顯示憑證錯誤，反而看不到登入頁。

補充：常用指令一覽

指令 打在哪 作用
ncpa.cpl Win + R 開「網路連線」，可停用／啟用網卡
services.msc Win + R 開「服務」，可重啟 WLAN AutoConfig
ipconfig /flushdns cmd 或 PowerShell 清除本機 DNS 解析快取
ipconfig /all cmd 或 PowerShell 看目前的 IP、閘道、DNS 伺服器
Get-NetAdapter PowerShell 列出所有網路介面卡與狀態
Restart-NetAdapter -Name "Wi-Fi" PowerShell（系統管理員） 一行重啟 Wi-Fi 網卡，取代裝置管理員點兩次

⚠️ 存疑／更正

  • Gemini 說「重新啟動電腦，90% 的情況重啟後網卡圖示就會恢復正常」。這個 90% 是它自己編的數字，沒有來源，當作「通常有效」的口語即可，不要引用。
  • Gemini 沒有提到 Windows 快速啟動會讓「關機」無法真正重載驅動，這是為什麼要選「重新啟動」的關鍵理由，已在上面補上。
  • Gemini 建議的步驟都沒有用到 PowerShell 的 Restart-NetAdapter，那其實比在裝置管理員點兩次快得多，已補進指令表。
