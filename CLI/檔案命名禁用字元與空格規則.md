# 檔案命名禁用字元與空格規則

本篇重點 a–b，共 2 個

## 重點整理

(a) <mark style="background: #FF5582A6;">Windows／macOS 等現代作業系統禁止用在檔名中的特殊字元</mark>：<mark style="background: #ADCCFFA6;">`\ / : * ? " < > |`</mark> 這幾個符號，其中最容易被忽略的是<mark style="background: #FFB8EBA6;">結尾處的冒號 `:`</mark>——實測案例中使用者一直找不到問題字元，最後才發現是檔名結尾藏了一個冒號，導致系統拒絕重新命名。

(b) <mark style="background: #BBFABBA6;">空格是允許的</mark>：只要不使用上述那組禁用符號，檔名中間留空格在 Windows 和 macOS 都能正常命名，不會被系統拒絕。
