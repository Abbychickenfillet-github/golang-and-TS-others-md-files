本篇重點 a–j，共 10 個。 這兩個問題是同一次對話問的，看起來無關，其實都在問同一件事：「這個名字／這個比較結果，到底屬於誰、代表什麼」。

第一部分：:: 範疇解析運算子（Scope Resolution Operator）

(a) :: 唸作 Scope Resolution Operator（範疇解析運算子），作用是明確指出某個名稱（變數、函式、型別）屬於哪一個範疇（Scope）。

(b) 存取命名空間成員：std::cout 表示 std 命名空間裡的 cout 物件。這也是為什麼你會看到有人寫 using namespace std; 之後就可以只寫 cout。

(c) 存取類別的靜態成員或列舉：MyClass::staticMethod()、Color::Red。

(d) 在類別外部定義成員函式：

class MyClass {
public:
    void myFunc();      // 宣告在標頭檔
};

void MyClass::myFunc() { /* ... */ }   // 定義在 .cpp，:: 說明它屬於 MyClass

(e) 前面不接任何名稱時，代表全域範疇。當區域變數與全域變數同名時，::x 明確指定要取全域的那一個。

int x = 10;          // 全域
void f() {
    int x = 20;      // 區域，遮蔽了全域的 x
    std::cout << x;  // 20
    std::cout << ::x;// 10  ← 這裡的 :: 前面是空的
}

(f) 常見混淆：:: 與 .、-> 完全不同。:: 處理的是編譯期的名稱歸屬；. 與 -> 處理的是執行期某個物件實例的成員存取。

第二部分：partial_ordering 偏序比較（C++20）

(g) 背景：C++20 引入三向比較運算子 <=>（俗稱太空船運算子，spaceship operator），一次比較就同時得到「小於／等於／大於」的資訊，不必再分別寫 <、==、>。

(h) 偏序（Partial Order）的意思是：不保證任意兩個值都能比出大小。最經典的例子是浮點數的 NaN（Not a Number）——它既不小於、也不等於、也不大於任何浮點數，包括它自己。

(i) std::partial_ordering 是 x <=> y 可能的回傳型別之一，它的四個值：

值 意義
less 小於
equivalent 等價
greater 大於
unordered 無法比較（例如與 NaN 比）

unordered 就是「偏序」跟另外兩種排序的分水嶺。三種比較類別的差別：

型別 有 unordered？ 等價是否代表可互換 典型用途
std::strong_ordering 否 是（完全相等） 整數、字串
std::weak_ordering 否 否（等價但可區分，例如忽略大小寫比字串） 自訂排序鍵
std::partial_ordering 是 否 浮點數

轉換方向只有單向：strong_ordering → weak_ordering → partial_ordering 可以隱式轉換，反過來不行。也就是說強的可以當弱的用，弱的不能冒充強的。

(j) std::partial_order 則是 <compare> 標頭檔提供的自訂點物件（Customization Point Object，CPO），也就是一個函式物件：呼叫 std::partial_order(a, b) 會回傳 std::partial_ordering。留意 partial_order（函式物件）與 partial_ordering（結果型別）差一個字尾，很容易看錯。

#include <compare>
#include <cmath>

double a = 1.0, nan = std::nan("");
auto r = a <=> nan;                    // std::partial_ordering::unordered
bool ok = (r == std::partial_ordering::unordered);   // true

申論題為什麼浮點數的比較需要用 partial_ordering，而不是 strong_ordering？
因為浮點數有 NaN（Not a Number）。NaN 對任何值（包含它自己）都既不小於、也不等於、也不大於，所以「任兩個值都能比出大小」這個全序前提在浮點數上不成立。

partial_ordering 多提供一個 unordered 值來表達這種「無法比較」的狀態，這就是偏序（partial order）跟全序（total order）的分界。整數、字串沒有這種例外值，所以用 strong_ordering 就夠。

(1) 存取命名空間成員：std::cout。
(2) 存取類別的靜態成員或列舉：MyClass::staticMethod()、Color::Red。
(3) 在類別外部定義成員函式：void MyClass::myFunc() { ... }，用來說明這個實作屬於 MyClass。
(4) 存取全域範疇：::x，前面不接任何名稱，用來穿透區域變數的遮蔽。
