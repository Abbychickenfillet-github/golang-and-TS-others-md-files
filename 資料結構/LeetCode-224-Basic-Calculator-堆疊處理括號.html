重點整理

  • (a) 題目：LeetCode 224 Basic Calculator 要求計算只含 +、-、括號與空格的算式字串。
  • (b) 核心思路：單次掃描 O(N) + stack（堆疊）。只有加減沒有乘除，所以不需處理運算子優先順序，難點只在「括號會把正負號展開」。
  • (c) 維護三個狀態：result（目前累加和）、sign（目前數字的正負號，1 或 -1）、number（正在讀的多位數）。
  • (d) 遇到數字：number = number * 10 + digit，逐位組成多位數。
  • (e) 遇到 + 或 -：先把 sign * number 加進 result，number 歸零，再更新 sign。
  • (f) 遇到 (：把 result 與 sign 依序 push 進 stack，然後 result = 0、sign = 1，括號內當成獨立的新算式。
  • (g) 遇到 )：先結算括號內最後一個數字，再 pop 出括號前的 sign 與 result，用 result = prevResult + prevSign * result 合併回外層。
var calculate = function (s) {
  let stack = [], result = 0, number = 0, sign = 1;
  for (const ch of s) {
    if (ch >= '0' && ch <= '9') number = number * 10 + (ch - '0');
    else if (ch === '+' || ch === '-') {
      result += sign * number; number = 0;
      sign = ch === '+' ? 1 : -1;
    } else if (ch === '(') {
      stack.push(result, sign);          // 先 push result 再 push sign
      result = 0; sign = 1;
    } else if (ch === ')') {
      result += sign * number; number = 0;
      const prevSign = stack.pop();      // 後進先出：先 pop 出 sign
      const prevResult = stack.pop();
      result = prevResult + prevSign * result;
    }
  }
  return result + sign * number;
};
項目 複雜度 原因
時間 O(N) 只掃描字串一次
空間 O(N) stack 大小取決於括號最大巢狀深度

範例 (1+(4+5+2)-3)+(6+8) 結果為 23，內層 (4+5+2)=11，併回外層 1+11=12，再 -3 得 9，最後 +14 得 23。
