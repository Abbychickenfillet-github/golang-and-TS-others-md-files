a. 職位核心職能分析：WeMo 是共享電動機車服務，後端系統核心在於處理「高併發與即時性」(大量 IoT 車輛設備即時上傳的位置/狀態數據)、「分散式系統架構」(High Availability、Scalability)、「異質系統整合」(金流如 LINE Pay/信用卡、Google Maps API、IoT 硬體通訊協定)，以及「自動化運維」(CI/CD、AWS/GCP 雲端基礎設施)。

b. 預測技術面試題(可作為面試前自我演練清單):

  2. API 設計與效能：App 需即時顯示地圖上數百台車輛位置，如何設計後端 API 降低延遲與伺服器負載？

  4. 微服務溝通：金流服務回應緩慢時，如何避免「雪崩效應」拖垮其他核心服務？(考點：熔斷器 Circuit Breaker 機制)
