重點整理

(a) bootstrap-theme.css 是舊版產物舊版（Bootstrap 3）提供 bootstrap-theme.css 當預設佈景。Bootstrap 5 已沒有這個檔案，客製主題改為覆寫 Sass 變數（Sass variables）後重新編譯。
(b) .min.css 只是縮小化min＝minified（縮小化）：移除空白與註解以縮減檔案大小、加速載入。它仍是完整樣式表，不是客製化模組。
(c) npm i bootstrap 的做法npm i bootstrap 會把檔案下載到 node_modules，之後在程式碼 import 需要的 CSS（或 Sass 原始碼自行編譯）。
