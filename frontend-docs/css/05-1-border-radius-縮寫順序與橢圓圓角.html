border-radius 縮寫順序—為什麼它不像 margin 繞圈圈

🔖 本篇重點索引：a–i，共 9 個。

重點整理

(a) 先破除最大的誤會：border-radius 的縮寫邏輯跟 margin／padding 完全不同。margin 是「邊」的四方向繞圈（上→右→下→左），border-radius 是「角」的對角線分配——省略的值是拿「對角」來補，不是拿「對邊」來補。

(b) 四值完整寫法的起點與方向：從左上角開始，順時鐘——左上 → 右上 → 右下 → 左下。

/* 左上 | 右上 | 右下 | 左下 */
border-radius: 0px 20px 40px 20px;

(c) 值的數量對照表（背這張就夠）：

值的數量 對應位置 省略規則
1 個值 四個角全部相同 —
2 個值 ①左上＋右下，②右上＋左下 兩組對角各一個值
3 個值 ①左上，②右上＋左下，③右下 中間那個值管兩個對角
4 個值 左上 → 右上 → 右下 → 左下（順時鐘） —

(d) 直接解 Abby 的原題：border-radius: 0px 20px 40px; 三個值分別是——

  • 第一個 0px → 左上角（Top-left）
  • 第二個 20px → 右上角（Top-right）與 左下角（Bottom-left），這兩個是一組對角
  • 第三個 40px → 右下角（Bottom-right）

所以答案不是「哪邊是上下、哪邊是左右」——border-radius 根本沒有上下左右的概念，只有四個角，這正是題目本身容易卡住的原因。

(e) 好記的心法：想像從左上角出發、順時鐘繞一圈。給幾個值就走幾步，走不完的角，就抄「它正對面那個角」的值。三值時右下（第三步）已經寫了，剩下的左下（第四步）就抄它的對角右上，所以右上與左下同值。

(f) 寫不確定時的兩個保險做法：

/* 保險做法一：一律寫滿四個值，不靠省略規則 */
border-radius: 0px 20px 40px 20px;

/* 保險做法二：拆成長寫法，語意最清楚、code review 也最好讀 */
border-top-left-radius: 0px;
border-top-right-radius: 20px;
border-bottom-right-radius: 40px;
border-bottom-left-radius: 20px;

(g) 進階—斜線 / 語法可以做橢圓圓角：border-radius 的每個角其實吃兩個半徑（水平 rx 與垂直 ry）。斜線前面那組是全部角的水平半徑，後面那組是垂直半徑。不寫斜線時，垂直半徑預設等於水平半徑，圓角就是正圓弧。

/* 水平半徑 / 垂直半徑 → 每個角都是橢圓弧 */
border-radius: 50px / 20px;

/* 經典的「葉子形」按鈕 */
border-radius: 0 100% 0 100% / 0 100% 0 100%;

(h) 百分比的基準不一樣：border-radius 用 % 時，水平半徑以元素寬度為基準、垂直半徑以元素高度為基準（跟 padding 的 % 一律看寬度不同）。所以 border-radius: 50% 在正方形上得到正圓，在長方形上會得到橢圓。

(i) 半徑過大時瀏覽器會等比縮小：若相鄰兩個角的半徑加起來超過該邊的長度，瀏覽器不會報錯，而是把所有半徑乘上同一個縮放係數直到剛好塞得下。這就是為什麼寫 border-radius: 9999px 可以安全地做出膠囊（pill）形狀——不用去算元素高度的一半。
