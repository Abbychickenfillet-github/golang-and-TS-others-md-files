style.setProperty：DOM 方法、JS 呼叫

本篇重點 a–d，共 4 個

重點整理

  • (a) deck.style.setProperty('--x', v) 是 DOM（CSSOM）提供的 API，由 JavaScript 呼叫。它是 CSSStyleDeclaration 物件的方法，可設定一般 CSS 屬性與 CSS 變數（custom property）。
  • (b) 寫在編輯器的那一行是 JavaScript 語法，不是 IDL。Web IDL（Interface Definition Language）是 W3C／WHATWG 規格書用來宣告「瀏覽器要提供哪些介面給開發者」的語言，setProperty 的簽名是在規格中以 Web IDL 定義，瀏覽器再實作成 JS 可呼叫的方法。
  • (c) BNF（Backus-Naur Form）是描述語法的標記法，只能「寫規則」，不能執行，也不能設定元素或物件屬性。規格裡 property ::= value 只是在定義允許的語法。
  • (d) 要幫元素設屬性用 el.style.setProperty()；幫一般 JS 物件設屬性用 obj.x = v、Object.defineProperty()。setProperty 只作用於 CSSStyleDeclaration。
