👉 展開參考答案
因為預設的content-box會讓「寫在CSS裡的width數字」跟「畫面上實際看到的總寬度」不一致，只要加了padding或border，總寬度就會比width數字大，之後只要改一次padding就得重新心算一次width才能維持版面不跑掉，非常容易出錯也難維護。改成border-box後，width寫多少、畫面上就是多少，padding和border只會往內壓縮content區，不會撐大外層總尺寸，跟響應式版面（RWD）或Grid/Flex排版搭配時也更好預測，這是為什麼幾乎所有CSS reset（包括normalize.css的延伸寫法）都會加上這一行。
