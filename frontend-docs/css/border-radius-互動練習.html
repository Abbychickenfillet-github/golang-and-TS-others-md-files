申論題（先自己講一遍，再展開對照）

  
Q1 為什麼 border-radius 用「對角」補值，而 margin 用「對邊」補值？這樣設計的道理是什麼？
    
參考方向：margin 描述的是四條「邊」的距離，視覺上對稱的是上下一組、左右一組，所以兩值寫法讓上下同值、左右同值最直覺。border-radius 描述的是四個「角」，一個矩形在視覺上的對稱軸是兩條對角線，讓對角同值才能得到常見的對稱造型（例如聊天泡泡、票券缺角）。兩者補值規則不同，是因為它們描述的幾何對象與常見對稱需求不同，不是規範不一致。

  
Q2 團隊 code review 時，你會建議統一寫四值、還是允許用縮寫？請說出理由與取捨。
    
參考方向：可主張「四值或長寫法」優先，理由是省略規則需要讀者在腦中還原，容易在維護時改錯角；縮寫的好處是行數短、diff 小。折衷做法是把常用圓角抽成 CSS 變數（--radius-sm/md/pill）由設計系統統一提供，一般元件只寫變數不寫數值，只有特殊造型才允許手寫四值並加註解。這樣兼顧可讀性與一致性。

  
Q3 要做一個「左上與右下是直角、右上與左下是大圓角」的卡片，你會怎麼寫？為什麼三值寫法在這裡剛好夠用？
    
參考方向：border-radius: 0 40px; 兩值就夠——第一值管左上＋右下（0），第二值管右上＋左下（40px），剛好對應題目的兩組對角。這正好是「對角補值」規則的最佳使用時機；若需求換成「上面兩角圓、下面兩角直」，對角規則就幫不上忙，必須寫成四值 border-radius: 20px 20px 0 0;。
