g 自我測驗

1. 切換 data-theme 會讓 Sass 變數固定。
非。固定的原因是 Sass 變數在打包時就被換成實際值；data-theme 只是 <html> 上的屬性，只能影響還留在 CSS 裡的 var()。
2. contrast-color() 可以回傳自選的深灰色 #1a202c。
非。依 MDN，回傳值只會是 white 或 black。要用自選的深灰，用成對 CSS 變數或 Sass 函式。
3. 填空：#1a202c 的 oklch 彩度 C 約是 ____，所以它是帶一點 ____ 的近黑。
0.025；藍（色相 H 約 264 度）。
