🧠 Effect 的心智模型：只有兩個動作

Effect 就是一段「讓元件和外部系統保持同步」的邏輯。它只有兩個狀態、兩個動作，其他的複雜度都來自「什麼時候觸發這兩個動作」

🔁 兩個狀態、兩個動作

💤 沒有同步外部系統沒連著
開始同步＝ setup（connect）
➡️
⬅️
停止同步＝ cleanup（disconnect）
🔗 同步中外部系統連著
不管事件是掛載、更新還是卸載，Effect 自己只會做這兩件事：開始或停止。「重新同步」就是先停止再開始

⚡ 什麼事件會觸發這兩個動作

事件實際的動作狀態變化
元件掛載（mount）開始💤 ➜ 🔗
deps 變了停止➜開始🔗 ➜ 💤 ➜ 🔗
元件並沒有卸載
re-render 但 deps 沒變什麼都不做🔗 維持
元件卸載（unmount）停止🔗 ➜ 💤
開發模式 StrictMode，掛載時開始➜停止➜開始🔗 ➜ 💤 ➜ 🔗
故意多演練一次

❓ 「只有兩個動作」有那麼簡單嗎？動作確實只有兩個，但這五件事要知道

① 動作少，觸發的事件多上表有五種情況。讀官方文件時，要先分清楚是哪個事件在觸發
② 一個元件可以有很多個 Effect每個 useEffect 是獨立的一組，各自在兩個狀態間切換，互不干擾
③ 每一輪同步用的是「那一次 render 的值」停止用舊值，開始用新值，這是閉包的結果
④ 停止可以是空的沒寫 return cleanup 的 Effect，「停止」什麼都不會做
⑤ 想讀最新值又不想重新同步用 Effect Event（useEffectEvent），它讀得到最新的 props 與 state，但不會讓 Effect 重新同步
