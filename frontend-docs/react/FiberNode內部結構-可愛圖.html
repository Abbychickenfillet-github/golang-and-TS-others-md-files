🧩 FiberNode

🏷️ typeCounter 函式本人
🚂 memoizedState指向 Hook 鏈的第一格
🔁 updateQueue指向 Effect 的環（見下方）

🚂 Hook 鏈：單向火車，尾巴是 null，不是環

React 依照你呼叫 Hook 的順序，一節一節掛上去（所以 Hook 不能寫在 if 裡）
🧠Hook ①useStatememoizedState = 值
➡️next
⚡Hook ②useEffectmemoizedState = Effect
➡️next
📦Hook ③useRefmemoizedState = {current}
➡️next
🚫null 到此為止
⚡ 打開 Effect 物件
🔌 createsetup 函式
📋 deps依賴陣列
🧹 inst.destroycleanup 函式
🔗 next指向下一個 Effect

🔄 真正的「環」在這：Effect 清單

fiber.updateQueue.lastEffect 指向最後一個，最後一個的 next 繞回第一個
⚡Effect A
➡️
⚡Effect B
➡️
⚡Effect C
↩️ C 的 next 回到 A（環）

✏️ 對照你的手繪

✅memoizedState 接出一條單向鏈：對
✅useEffect 帶依賴陣列與 cleanup：對
⚠️Hook 鏈不是環，最後一節的 next 是 null
⚠️deps 與 cleanup 住在 Effect 物件裡，不是直接掛在 Hook 上
💡「環」指的是 updateQueue 的 Effect 清單
