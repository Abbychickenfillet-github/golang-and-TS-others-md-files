🚂 Hook 鏈：單向火車，尾巴是 null，不是環

React 依照你呼叫 Hook 的順序，一節一節掛上去（所以 Hook 不能寫在 if 裡）。每一節都是同一種 Hook 物件，差別只在 memoizedState 裡放什麼

🎒 Heap 上的 Context（閉包背包）

🎒 Context ②（setup() 那一次呼叫）cleanup 背著它
previous ➜ Context ①
connection = 連線物件
⬇️ previous（往外一層）
🎒 Context ①（ChatRoom() 那一次 render）setup 背著它

cleanup 之後還能 disconnect「當初那一條」連線，靠的就是 ② 這個背包

✏️ 對照你的手繪

✅memoizedState 接出一條單向鏈：對

⚠️Hook 鏈不是環，最後一節的 next 是 null

💡環在 Effect 清單與 pending 更新清單
