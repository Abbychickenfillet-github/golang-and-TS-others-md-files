🎛️ fiber.mode 的開關板：一個數字裝七個開關

mode 就是一個普通的數字（typeof mode === 'number'）。把它寫成二進位，每一個位置（位元）就是一個「開／關」開關。以開發模式為例，數字都是實際執行得到的。

① 七個開關各是什麼（HostRoot 開發模式：0000011 ＝ 3）

由右往左數：第 0 位、第 1 位……亮綠燈表示這個開關是 1（開）。HostRoot 是 ConcurrentMode 加 ProfileMode

子 fiber 建立時，直接把「父 fiber 的 mode 這個數字」複製過來（原始碼：createFiberFromElement(element, returnFiber.mode, lanes)），所以開關狀態會一路往下繼承

② mode |= StrictLegacyMode 一步一步

| 是位元 OR：兩個數字對齊，每一位只要有一個是 1，結果就是 1。|= 是「算完再存回 mode」，等於 mode = mode | StrictLegacyMode

怎麼檢查開關是不是開的：&（位元 AND，兩邊都是 1 才是 1）
27 & 80001000＝ 8，不等於 0（!== NoMode），開
3 & 80000000＝ 0（=== NoMode），關
關掉開關：mode &= ~StrictLegacyMode（~ 是把每一位反過來）

④ 誰在讀這些開關（原始碼實際位置）

開關誰在讀用來做什麼
StrictLegacyModerenderWithHooks：workInProgress.mode & StrictLegacyMode決定要不要把元件函式呼叫兩次（雙重 render）
StrictEffectsModemountEffect：currentlyRenderingFiber.mode & StrictEffectsMode開啟時，替這個 Effect 多加上 MountPassiveDevEffect 旗標
StrictEffectsMode 與 StrictLegacyModecommitDoubleInvokeEffectsInDEV：檢查 root.current.mode只決定「從 root 開始是不是已經在嚴格模式內」。遇到 <StrictMode> 的 fiber 時，是看它的型別（fiber.type === REACT_STRICT_MODE_TYPE）
PlacementDEV（在 fiber.flags，不是 mode）ReactChildFiber 新建 fiber 時：flags |= Placement | PlacementDEV標記「剛被放進畫面」，才輪得到額外一輪 Effect。flags 也是同一種位元旗標手法
