🥫 useEffect 的 setup 與 cleanup：Call Stack 罐頭時間軸

以 <ChatRoom /> 為例：一個 useEffect，經過「第一次掛載 → 依賴變動」兩輪。左邊是 Call Stack（罐頭疊），下面是 Heap 上的 Effect 物件
❌ 常見的想像setup 罐頭先進 stack，cleanup 罐頭疊在它上面，所以 cleanup 先彈出
✅ 實際情況cleanup 從來沒有跟 setup 同時在 stack 上，它是被 React 在「之後另一次」呼叫的，先後由 React 的 commit 排程決定
🥫 Call Stack 是後進先出（LIFO）它只決定「同一時間疊在一起」的函式誰先彈出，例如 flushPassiveEffects 呼叫 setup()，一定是 setup() 先彈出
🔄 同一次 commit 的順序React 先跑完所有要清理的 cleanup（commitPassiveUnmountEffects），再跑所有 setup（commitPassiveMountEffects）
🏠 cleanup 住在哪fiber → Hook ② 的 memoizedState → Effect 物件 → inst.destroy，不在 queue，也不在 Hook 的 next
