重點整理

(a) id="root" 只是慣例HTML 與瀏覽器不會替 id="root" 的 div 加任何內建功能。React 教學習慣用它當掛載點（mount point，框架接管畫面渲染的起點 DOM 節點）。
改名成 app 或 main-container 也能運作，只要 getElementById 抓同一個名字。
(b) createRoot().render() 是全域掛載React 18 寫法：createRoot(document.getElementById('root')) 先對該 DOM 節點建立 root 物件，再呼叫 root.render(<App />) 把整個應用塞進去。舊版是 ReactDOM.render()。
(c) 類別元件才需要元件內 render()Class Component（類別元件）必須實作 render() 並回傳 JSX。Functional Component（函數元件）整個函數本身就是渲染函式，直接 return JSX，所以日常元件看不到 render。
(d) 兩種 render 層級不同① root.render()＝把整個 React 應用掛到 DOM（全域，一次）。② 類別元件的 render()＝決定單一元件長相（元件內，每次更新）。
