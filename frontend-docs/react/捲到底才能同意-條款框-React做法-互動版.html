捲到底才能同意｜Scroll-to-Agree 互動版

筆記：捲到底才能同意-條款框-React做法　來源：next-one-time-tracker issue #8

a 流程圖（ISO 5807 符號）

符號名稱（ISO 5807）圖中用在
圓角矩形Terminator 起止開始、結束
矩形Process 處理步驟鎖住鈕、使用者捲動、解鎖鈕
菱形Decision 決策看得完嗎？、捲到底了嗎？

看得完：條款短，整段都在框內，沒有可捲的內容，載入就解鎖。看不完：使用者要捲，每次捲動都再判斷一次，直到捲到底。

b 實際操作

請捲到條款最底部後才能同意
目前做法A
handler / callback 次數0
scrollTopElement 的屬性（property），可讀可寫，不是方法，讀取時不加括號。
值 = 這個元素的內容已經往上捲掉幾 px，也就是可視框上緣離內容頂端的距離。0 = 還沒捲。可能有小數。		0
clientHeightElement 的唯讀屬性（property），不是方法。
值 = 元素可視那一格的高度（px、整數）= CSS height + padding - 水平捲軸高度；不含 border、margin。這裡就是條款框一次看得到的高度。		0
scrollHeightElement 的唯讀屬性（property），不是方法。
值 = 這個元素內容的總高度（px、整數），包含因 overflow 被藏起來、要捲才看得到的部分。是元素自己的內容高度，不是整個 HTML 頁面的高度。		0
剩餘可捲距離不是瀏覽器屬性，是這個頁面自己算的：
scrollHeight - clientHeight - scrollTop。0 = 到底。
不是 scrollHeight - scrollTop：可視框本身已經看得到 clientHeight 那麼高，要再扣掉。		0
reachedEndfalse

A 每次捲動都會計次；B 只在 sentinel 進出可見範圍時計次。捲到底後往上捲，reachedEnd 保持 true。把滑鼠移到 scrollTop、clientHeight、scrollHeight、剩餘可捲距離上，看定義。

d 自我測驗



  

    1. 判斷捲到底可以寫 scrollTop === scrollHeight - clientHeight。

    
    
非。scrollTop 可能有小數，而 scrollHeight、clientHeight 是整數，會永遠不相等。改用 >= 加 1px 容差。

  

  

    2. IntersectionObserver 的 root 不設，也能偵測條款框內的 sentinel。

    
    
非。root 預設是整個 viewport，要設成捲動容器。

  

  

    3. 填空：條款短到不用捲時，A 要在 ____ 檢查一次；B 靠 ____ 後 callback 先跑一次。

    
    
mount（useEffect）；observe()。
