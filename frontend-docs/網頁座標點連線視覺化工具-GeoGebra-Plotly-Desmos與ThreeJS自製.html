網頁版座標點連線視覺化工具：GeoGebra、Plotly、Desmos 與自己用 Three.js／p5.js 做

本篇重點 a–i，共 9 個。需求是「在網頁上輸入一組座標點，讓它自動連線成幾何模型」，分成「現成工具」與「自己寫」兩條路。

重點整理

一、四個現成的網頁工具

(a) GeoGebra（幾何數學工具） — https://www.geogebra.org/3d ：目前功能最完整且免費的網頁數學工具。輸入座標點如 A=(1,2,3)，再用指令 Polygon(A, B, C, D) 或 Line(A, B) 建立連線模型。支援 3D 空間與參數方程並可即時預覽，適合數學建模與精確幾何構圖。

(b) Plotly Chart Studio — https://chart-studio.plotly.com/ ：手上已有大量資料點（CSV 或 Excel）時最順手。支援 3D Scatter Plot，匯入座標後在設定選 lines 或 lines+markers 模式，它就會依照「點的順序」連線。適合資料科學、路徑追蹤、科研繪圖。

(c) Tinkercad Codeblocks — https://www.tinkercad.com/codeblocks ：Autodesk 旗下線上建模工具，用邏輯積木或座標點生成 3D 模型。偏向實體建模，適合 3D 列印前置設計。

(d) Desmos 3D Graphing Calculator — https://www.desmos.com/3d ：操作最直覺。列一個點清單 L=[(0,0,0),(1,2,3),...] 再用連線功能觀察空間形狀，適合快速視覺化與輕量測試。

(e) 選擇原則：要「精確幾何與教學」選 GeoGebra；要「大量資料點與圖表輸出」選 Plotly；要「快速看一眼」選 Desmos；要「做成實體」選 Tinkercad。

二、自己寫：Three.js 與 p5.js

  • Three.js ＝ 建構在 WebGL 之上的 3D 函式庫，WebGL ＝ Web Graphics Library，瀏覽器的硬體加速繪圖 API。
  • p5.js ＝ Processing 的 JavaScript 版，主打創意編碼（creative coding），API 比 Three.js 簡單很多。

(f) Three.js 做法：用 THREE.BufferGeometry 的 setFromPoints 把座標陣列直接轉成線條模型。

// points 是一組 THREE.Vector3
const points = [
  new THREE.Vector3(0, 0, 0),
  new THREE.Vector3(1, 2, 3),
  new THREE.Vector3(2, 0, 1),
];

// BufferGeometry 是把頂點資料塞進 GPU 緩衝區的幾何體
const geometry = new THREE.BufferGeometry().setFromPoints(points);

// LineBasicMaterial 是「線」專用的材質，不受光照影響
const material = new THREE.LineBasicMaterial({ color: 0x3355ff });

// THREE.Line 會依照 points 的「陣列順序」依序連接
const line = new THREE.Line(geometry, material);
scene.add(line);

一行一行的意思：先準備一組三維向量當頂點；setFromPoints 把它們展平成一個 Float32Array 存進 GPU 緩衝區（這就是 Buffer 的由來，比舊的 Geometry 省記憶體）；材質決定線的顏色；THREE.Line 這個物件負責「依序把相鄰兩點連起來」，所以陣列順序錯了，圖形就會錯；最後把它加進場景才會被渲染。

(g) p5.js 做法：在 draw() 裡用 beginShape()、vertex(x, y, z)、endShape(CLOSE)。

function draw() {
  background(240);
  beginShape();              // 開始收集頂點
  vertex(0, 0, 0);           // 逐點餵入座標
  vertex(100, 50, 0);
  vertex(50, 120, 0);
  endShape(CLOSE);           // CLOSE 代表把最後一點接回第一點，形成封閉多邊形
}

endShape(CLOSE) 的 CLOSE 是關鍵字，不加就只會畫出開放折線；要畫 3D 需先在 createCanvas(w, h, WEBGL) 指定 WEBGL 模式。

(h) 如果只是 2D 而且點數不多，其實用純 SVG 的 <polyline points="0,0 100,50 50,120"> 就夠了，不需要引入任何函式庫，檔案還能直接貼進 Obsidian 顯示。

(i) 共通陷阱：所有這些工具都是「依照你給的順序連線」，不會自動幫你算出最合理的連法。如果要的是「把一堆散點連成外框」，那是凸包（Convex Hull）演算法的問題，不是繪圖工具的問題。
