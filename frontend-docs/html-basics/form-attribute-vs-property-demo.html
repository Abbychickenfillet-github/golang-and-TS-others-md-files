content attribute vs IDL property — 可執行範例

搭配筆記 content-attribute-vs-IDL-property-與表單提交機制.md 的 §2 與 §3。

實驗 1：改一個字，看兩邊什麼時候分家

在下面的欄位裡打字。左欄是 JS 的 el.value（當前狀態），右欄是 HTML 的 getAttribute('value')（原始碼寫了什麼）。

讀法目前值屬於哪一套
el.value—IDL property（當前狀態）
el.getAttribute('value')—content attribute（原始碼）
el.defaultValue—content attribute 的 IDL 對口
el.name / el.id—完全反映，兩邊永遠一致
