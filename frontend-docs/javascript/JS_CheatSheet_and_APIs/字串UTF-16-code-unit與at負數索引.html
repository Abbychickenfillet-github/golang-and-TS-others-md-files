重點整理

(a) String 是 JavaScript 全域物件與建構子，字串字面值可用單引號 '、雙引號 " 或樣板字面值 ` 建立，這種稱為 primitive string，用 String() 轉型也得到 primitive，用 new String() 才得到物件。

(b) JavaScript 字串內部以 UTF-16 儲存，每個基本單位叫 code unit，長度 16 位元。 　原因：1995 年設計語言時，UTF-16 足以涵蓋當時 Unicode 的 BMP 範圍，所以沿用至今，並非選 UTF-8。

(c) Emoji 或罕見字超出 BMP，需要兩個 code unit（surrogate pair，代理對）表示。 　charAt()、at()、索引 str[i] 都以 code unit 為單位，遇到 Emoji 可能切到半個字元。這是用索引處理 Emoji 的陷阱。

(d) at() 是 ES2022 新增的方法，可傳負整數，從字串尾端倒數。

const s = "hello";
s.charAt(-1);      // ""（charAt 不支援負數，回傳空字串）
s[s.length - 1];   // "o"（舊寫法，較繁瑣）
s.at(-1);          // "o"（倒數第 1 個）
s.at(-2);          // "l"（倒數第 2 個）

(e) 常用實體方法：toLowerCase、toUpperCase、trim、replace、split、indexOf、substring。
