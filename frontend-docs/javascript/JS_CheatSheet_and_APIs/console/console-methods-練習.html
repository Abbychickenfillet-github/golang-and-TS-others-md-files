Console 方法家族練習

對應筆記 Console方法家族-一次講完.md｜資料來源 MDN console.table（2025-07-04 更新）與 MDN console（2025-02-13 更新）
使用方式：先按 F12 打開 DevTools 切到 Console 分頁，再回來按下面的按鈕。 所有輸出都印在主控台，這一頁本身不顯示結果 —— 因為重點就是要你去看 Console 長什麼樣。

a. table：三種輸入形狀

同樣的資料換三種包裝，表格的欄位就完全不同。

console.table(["apples", "oranges", "bananas"]);              // 原始值陣列 → (index) + Values
console.table([{firstName:"Tyrone"}, {firstName:"Janet"}]);   // 物件陣列 → 每個屬性一欄
console.table({ abby:{age:20}, bob:{age:30} });               // 物件的物件 → 屬性名當列標題
console.table(people, ["firstName"]);                         // 第二參數 → 只印指定欄

b. log 與 dir 的差別

傳 DOM 元素進去，兩者的輸出完全不一樣。這是最多人搞混的一組。

console.log(document.body);   // 印成 HTML 標籤樣子，像 Elements 分頁
console.dir(document.body);   // 印成可展開的屬性列表，看得到所有 JS 屬性
要看「一個物件有哪些屬性與原型」用 dir，要看 DOM 結構用 log。

c. 五種訊息等級

按完之後，去 DevTools 右上角的 Levels 下拉選單試著取消勾選，就懂為什麼要分等級了。

console.log("一般")｜console.info("資訊")｜console.warn("警告")
console.error("錯誤")｜console.debug("除錯，Chrome 預設隱藏")
debug 預設看不到，要在 Levels 勾選 Verbose 才會出現。

d. group：可摺疊的縮排群組

console.group("使用者資料");
console.log("name: Abby");
console.groupEnd();
groupCollapsed 預設是收合的，資料多的時候用它比較不會洗版。

e. time 與 count：計時與計次

console.time("排序");  bigArray.sort();  console.timeEnd("排序");
console.count("按了幾次");   // 每按一次數字加一

f. assert 與 trace

assert 的邏輯是反的：條件為 false 才印，為 true 時完全靜音。

console.assert(user.age >= 18, "未成年", user);   // age < 18 才會印
console.trace();                                  // 印出完整呼叫堆疊

g. %c：把 log 加上 CSS 樣式

console.log("%c重點", "color:#8b5cf6; font-weight:bold; font-size:16px");
console.log("%s 今年 %d 歲", "Abby", 20);

h. 陷阱：log 印物件不是快照

Chrome 對物件是「展開時才求值」，所以你之後改了物件，點開看到的可能已經是新值。

const o = { n: 1 };
console.log("直接印", o);                              // 展開後可能看到 n: 2
console.log("快照", JSON.parse(JSON.stringify(o)));    // 這個才是當下的值
o.n = 2;
按完把第一行的三角形點開，看 n 是 1 還是 2。
