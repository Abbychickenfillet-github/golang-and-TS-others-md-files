重點整理

(a)parseInt() 是解析器（Parser）：從字串開頭逐字讀取，盡可能解析出整數，遇到第一個非數字字元就停止，允許字串尾巴接非數字內容。parseInt("100px") 結果是 100。

(b)Number() 是強制型別轉換（Type Coercion）：要求整串字串都符合合法數字格式，只要含有任何非數字字元（正負號、小數點、科學記號除外），整串直接判定失敗、回傳 NaN。Number("100px") 結果是 NaN。

(c)對空字串與特殊值的處理，兩者常常不一致，容易誤判：

輸入值 parseInt() Number() 說明
""（空字串） NaN 0 Number() 把空字串或純空格轉成 0
null NaN 0 Number(null) 是 0
undefined NaN NaN 兩者皆為 NaN
true / false NaN 1 / 0 只有 Number() 能轉換布林值

(d)小數點的處理方式完全不同：parseInt() 直接無條件捨去小數點後所有內容（parseInt("3.14") 為 3）；Number() 保留完整小數（Number("3.14") 為 3.14）。

(e)進位（radix）支援只有 parseInt 有：parseInt(string, radix) 支援第二個參數指定進制（如 2 進位、16 進位），例如 parseInt("10", 2) 為 2；Number() 不支援指定進制參數，只能自動識別字串中的 0x（十六進位）、0b（二進位）、0o（八進位）前綴。

parseInt("100px")        // 100  —— 容錯，讀到 p 就停
Number("100px")          // NaN  —— 嚴格，整串必須合法

parseInt("3.14")         // 3    —— 捨去小數
Number("3.14")           // 3.14 —— 保留小數

parseInt("10", 2)        // 2    —— 指定二進位
Number("0b10")           // 2    —— 只能靠前綴自動識別
Number("10", 2)          // 10   —— 第二個參數被忽略，不支援 radix

(f)使用建議：要抽取字串開頭的整數（例如從 CSS 單位 "20px" 取出 20）或需要處理進制轉換，用 parseInt()；要嚴格驗證整串字串是否為合法數字、且需要保留小數，用 Number()（或更專門解析浮點數的 parseFloat()）。
