1. 不可變性再覆述一次（a）

(a) 原始型別的值不能被修改，重新賦值改變的是「變數指向哪個記憶體位址」，不是原本位址上的值：let name = "Alice" 時 name 指向存 "Alice" 的位址；name = "Bob" 是在新位址存 "Bob"，讓 name 改指向新位址，原本 "Alice" 那格沒有被動過，之後沒有變數再指向它就會被 GC 回收。物件則相反：let user = {name:"Alice"}; user.name = "Bob" 是在同一個記憶體位址上直接改內容。完整的四層 immutable 拆解、與 Object.freeze 的關係，見 [[Day1-型別辨別-自動轉換-與immutable的四個層次]]。

2. Console 除錯案例：變數名打錯導致誤判（b）

(b) 字串比較 ===／== 一定是大小寫敏感（case-sensitive）的，"string" === "String" 必然是 false。Abby 在 Console 印出 true 的原因不是語言規則例外，而是打字時比較的變數名跟宣告的變數名不一致——宣告了 c、d，但 console.log 裡誤寫成比較 a、b，而 Console 之前的操作歷史裡 a、b剛好被賦過相同的值，所以印出 true。

let c = "string";
let d = "String";
console.log(a == b);   // 比的是 a、b，不是 c、d！
console.log(a === b);  // 同上

🔧 除錯技巧：懷疑變數作用域或殘留值有問題時，直接比對字面值（string literal）排除變數污染：console.log("string" === "String") 必然印出 false，若結果不同，問題出在變數本身而非語言規則。

3. 箭頭函式隱式回傳複習（c）

(c) 箭頭函式省略大括號 {} 時，會自動把後面的運算式（Expression）結果當回傳值，稱為隱式回傳（Implicit Return）／運算式主體（Expression Body）；一旦加上 {}（區塊主體／Block Body），就必須手動寫 return，否則預設回傳 undefined：

// 隱式回傳：單一運算式，不用 return，不用 {}
const areEqualInUpperCase = (str1, str2) =>
  str1.toUpperCase() === str2.toUpperCase();

// 明確回傳：加了 {} 就要自己寫 return
const areEqualInUpperCase2 = (str1, str2) => {
  return str1.toUpperCase() === str2.toUpperCase();
};

語法上更精確的講法：箭頭函式省略 {} 時後面只能接「單一運算式（Single Expression）」，不能放「陳述式（Statement，如 if、for、const x=1;）」；「有沒有 {}」才是判斷 Implicit／Explicit Return 的關鍵，這個規則的完整推演見 [[箭頭函式的兩組括號-參數小括弧與主體大括弧-隱式回傳]]。

4. localeCompare：語系敏感的字串比較（d–e）

(d) localeCompare() 是 JS 內建、語系敏感（Locale-aware）的字串比較方法，設計邏輯類似 C 語言的 strcmp()：回傳 0 代表相等，負數代表第一個字串排序在前，正數代表排序在後。

"a".localeCompare("b"); // 負數，"a" 排在 "b" 前面
"b".localeCompare("a"); // 正數，"b" 排在 "a" 後面
"a".localeCompare("a"); // 0，相等

(e) 帶入語言代碼（ISO 639-1）可以讓比較符合該語言的拼字／字母等價規則，因為不同語言對「大小寫」與「字母等價性」的規則不同：

// 德語（de）：ß 與 ss 視為相同字母
"ß".localeCompare("ss", "de", { sensitivity: "base" }); // 0（相等）

// 土耳其語（tr）：無點小寫 ı 的大寫是 I，帶點小寫 i 的大寫是 İ，兩套系統不同
"ı".localeCompare("I", "tr", { sensitivity: "base" }); // 0（相等）

de = 德語（German），tr = 土耳其語（Turkish），皆為 ISO 639-1 語言代碼。

5. charAt 是 zero-based index（f）

(f) charAt() 使用 zero-based index（以 0 為起始的索引）：第一個字元索引是 0，最後一個字元索引是 string.length - 1。

const str = "cat";
str.charAt(0); // "c"
str.charAt(1); // "a"
