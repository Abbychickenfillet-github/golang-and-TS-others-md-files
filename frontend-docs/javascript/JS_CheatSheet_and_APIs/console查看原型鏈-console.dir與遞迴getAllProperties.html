重點整理

(a) 最簡單：console.dir(x)，展開後可看自身屬性與 __proto__（原型鏈上的方法）。 　傳入實例（如 []）：展開 __proto__ 看原型方法。 　傳入建構子（如 Array）：自身屬性就是 static 方法（Array.from、Object.keys 同理）。

(b) 用程式碼走訪整條原型鏈，Gemini 給的遞迴版本：

function getAllProperties(obj) {
  let props = new Set();
  let cur = obj;
  if (typeof obj === 'function') {
    Object.getOwnPropertyNames(obj).forEach(p => props.add(`[Static] ${p}`));
  }
  while (cur) {
    Object.getOwnPropertyNames(cur).forEach(p => props.add(p));
    cur = Object.getPrototypeOf(cur);
  }
  return Array.from(props).sort();
}
console.log(getAllProperties([]));
console.log(getAllProperties(Array));

(c) ⚠️ 存疑/更正：Gemini 說 getAllProperties(Array) 能「同時看靜態與原型方法」。 　實際上 Array 這個函式的原型鏈是 Function.prototype → Object.prototype，不包含 Array.prototype，所以 map、push 不會出現。 　要看實例方法需另外呼叫 getAllProperties(Array.prototype)。
