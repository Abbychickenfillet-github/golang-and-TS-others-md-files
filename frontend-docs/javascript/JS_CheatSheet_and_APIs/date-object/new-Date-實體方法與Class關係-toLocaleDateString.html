new Date 實體方法與 Class 的關係——toLocaleDateString

重點整理

問題：下面這段程式碼一個 class 關鍵字都沒出現，為什麼說它跟 Class 有關？

const bigDay = new Date(2019, 6, 19);   // new：呼叫 Date 的建構子，產生實例
console.log(bigDay.toLocaleDateString()); // 呼叫實例方法，輸出在地化日期字串

a. Date 是 JavaScript 內建的 Class（建構函式）。內建型別（Date、Array、Object）早就由引擎寫好，使用者不必自己寫 class Date { ... }，看不到 class 關鍵字不代表沒有 Class。

b. new Date(...) 是「實體化（instantiate）」：new 運算子呼叫 Date 的建構子，建出一個全新物件，指派給 bigDay。bigDay 就是 Date 的實例（instance）。

c. toLocaleDateString() 是實體方法（instance method），定義在 Date.prototype 上。bigDay 自己身上沒有它，是沿著原型鏈（prototype chain）往 Date.prototype 找到的。
可驗證：bigDay.hasOwnProperty("toLocaleDateString") 為 false，Date.prototype.hasOwnProperty("toLocaleDateString") 為 true。

d. 記憶比喻：Date 是廠商做好的雞蛋糕模具（Class），new Date() 是倒麵糊烤出一個雞蛋糕（實例 bigDay），toLocaleDateString() 是模具規格裡附帶的切塊功能（方法）。

[!tip]+ 一句話
有 new X() 的地方，X 就是 Class（建構函式）。方法找不到於實例自身，就去 X.prototype 找。
