DOM 與 BOM 的物件化模型

1. 為什麼瀏覽器要把頁面跟視窗「物件化」（a–b）

(a) JavaScript 引擎不能直接理解 HTML 原始碼或瀏覽器視窗本身，所以瀏覽器會把這些東西轉化成 JS 看得懂的物件結構，才能被程式碼讀取與修改。HTML 原始碼只是純文字（例如 <button id="btn">按我</button>），瀏覽器解析後會建立對應的 JS 物件，掛上屬性與方法，例如 document.getElementById('btn') 拿到的 button 物件可以直接讀 button.textContent、寫 button.style.color = 'red'。

(b) DOM（Document Object Model）管頁面內容，BOM（Browser Object Model）管瀏覽器視窗本身，兩者是不同層級的物件化結果：

window   (BOM 頂層物件，代表瀏覽器本身)
└── document   (DOM 頂層物件，代表當前載入的 HTML 頁面)
    └── <html>
        └── <body>
            └── <button>   (頁面中的個別 HTML 元素物件)

DOM 部分：瀏覽器解析 HTML 時把每個標籤、文字、屬性都轉成一個個 JS 物件並組成樹狀結構（DOM Tree），根物件是 document。

BOM 部分：整個瀏覽器視窗（網址列、瀏覽歷史、螢幕解析度、視窗大小）被封裝成以 window 為頂層的物件，例如 window.location（網址，window.location.href = '...' 可轉址）、window.history（瀏覽歷史，window.history.back() 模擬上一頁）、window.navigator（使用者裝置與瀏覽器資訊）。

2. 樹狀導覽：原生 DOM 屬性 vs jQuery 方法（c–e）

(c) 「樹狀導覽（Tree Navigation）」屬性是 JavaScript 原生（Vanilla JS）的 DOM 屬性，不是 jQuery 專屬——parentNode、childNodes、firstChild、lastChild、previousSibling、nextSibling 全部是 DOM Level 1 標準就有的原生屬性。會覺得眼熟是因為 jQuery 本來就是為了封裝、簡化這些原生操作而設計的：

需求 原生 DOM 屬性 jQuery 方法
找父節點 node.parentNode $(node).parent()
找所有子節點 node.childNodes $(node).children()
找第一個子節點 node.firstChild $(node).children().first()
找最後一個子節點 node.lastChild $(node).children().last()
找前一個兄弟節點 node.previousSibling $(node).prev()
找後一個兄弟節點 node.nextSibling $(node).next()

(d) 原生 DOM 陷阱：Node（節點）包含文字節點、註解節點，不只有 Element（HTML 標籤）。用 childNodes／firstChild 存取時，換行與空格會被算成獨立的文字節點：

<div id="parent">
  <p>Hello</p>
</div>

const parent = document.getElementById('parent');
console.log(parent.firstChild);
// 拿到的不是 <p>！而是 <div> 與 <p> 之間的「換行＋空格」文字節點

(e) 解法是改用帶有 Element 字眼的現代屬性，只回傳真正的 HTML 元素、自動濾掉空白文字節點：parentElement、children（取代 childNodes）、firstElementChild（取代 firstChild）、lastElementChild（取代 lastChild）、previousElementSibling（取代 previousSibling）、nextElementSibling（取代 nextSibling）。這正是 jQuery 當年大受歡迎的原因之一——$(node).children() 自動濾空白，原生 DOM 後來才補上對應版本。

3. Property（屬性存取）vs Attribute（HTML 標籤屬性）（f–h）

(f) 原生 DOM 提供大量「Property（屬性）」，意思就是可以用點記號 . 直接讀寫，不用加括號呼叫。Property 代表物件的狀態／資料（直接存取），Method（方法）代表物件的行為／動作（要加 () 呼叫執行）：

// Property：直接讀寫，不加括號
const el = node.parentElement;
node.textContent = "Hello World";

// Method：要呼叫執行
node.appendChild(newChild);
document.getElementById("myId");

(g) 三類常見的可直接存取 Property：① 樹狀導覽（唯讀）如 box.parentElement、box.children、box.nextElementSibling；② 內容操作（可讀寫）如 title.textContent = '新標題'、title.style.color = 'red'；③ HTML 標籤屬性的直接映射（可讀寫）如 img.src = '...'、input.value = '...'、input.disabled = true。

(h) DOM Property 與 HTML Attribute 是兩個經常被混淆的概念：

概念 英文 存取方式 說明
DOM 屬性 Property 直接存取（如 element.className） 存在於 JS 物件記憶體中的變數，存取速度最快
HTML 屬性 Attribute 透過方法（如 element.getAttribute('class')） 寫在 HTML 原始碼裡的字串標籤

現代前端開發絕大多數情況都直接存取 DOM Property，既直覺又方便，只有在需要讀取「HTML 原始碼字面寫了什麼」時才會用 getAttribute()。
