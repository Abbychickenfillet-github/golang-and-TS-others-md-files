demo：on-event 處理器 vs addEventListener

搭配筆記：事件處理器vs事件監聽器-onevent與addEventListener.md　每個區塊先自己猜結果，再按按鈕驗證。

① 插槽會被覆蓋：btn.onclick 綁兩次

程式碼：btn.onclick = fnA; 然後 btn.onclick = fnB;

（等待點擊）

② 佇列會排隊：addEventListener 綁兩次

程式碼：btn.addEventListener('click', fnA) 與 btn.addEventListener('click', fnB)

（等待點擊）

③ 小括號陷阱：綁上去的是回傳值

程式碼：btn.onclick = sayHi();　注意頁面一載入 sayHi 就已經跑過一次了

（等待點擊）

④ once: true 執行完自己消失

程式碼：btn.addEventListener('click', fn, { once: true })

（等待點擊）

⑤ signal：想什麼時候拔掉就什麼時候拔

程式碼：addEventListener('click', fn, { signal: ac.signal })，按「解除監聽」後就失效
