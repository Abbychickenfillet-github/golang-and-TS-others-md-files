重點整理

a. Getter / Setter 不是 JavaScript 專屬的東西。它是物件導向程式設計（OOP，Object-Oriented Programming）實現「封裝（Encapsulation）」的通用機制，Java、Python、C# 都有。

b. 封裝要解決的第一件事是控制存取權限：把物件內部的欄位設為私有（private），只透過 Getter / Setter 暴露一個對外的存取介面，避免外部程式直接改動內部狀態。

c. 封裝要解決的第二件事是邏輯驗證與保護：可以在 Setter 裡加資料合法性檢查（例如年齡不可為負數），或在 Getter 裡回傳資料副本，防止外部拿到參考後直接改到原始物件。

d. 各語言對 class 的依賴程度（這是本篇最該記住的表）：

語言 是否必須寫出 class 運作方式
Java 是 Java 是純 class-based 語言，所有方法（含 Getter / Setter）都必須定義在 class 或 record 內
JavaScript 否 除了 class 內可以寫，也可以直接寫在物件字面值 const obj = { get x() {} }，或用 Object.defineProperty() 定義
Python 是（主要） 通常用 @property 裝飾器定義在 class 內部
C# 是 以屬性（Property）形式寫在 class 或 struct 內：public string Name { get; set; }

e. JavaScript 之所以能「不用 class」，根本原因是它是基於原型（prototype-based）而不是基於類別（class-based）的語言。JS 的 class 只是語法糖，底層仍是建構函式加原型鏈，所以存取器屬性本來就可以直接定義在任何一個物件上，不必先有類別。

f. 三種 JavaScript 寫法對照（詳細版請看 [[存取器屬性三種定義方式-getter-setter與資料驗證]]）：

// 寫法一：物件字面值（最輕量，不需要 class）
const user1 = {
  _age: 25,
  get age() { return this._age; },
  set age(v) {
    if (v < 0) throw new RangeError("年齡不可為負數");
    this._age = v;
  }
};

// 寫法二：Object.defineProperty（可額外控制 enumerable / configurable）
const user2 = {};
Object.defineProperty(user2, "age", {
  get() { return this._age; },
  set(v) { this._age = v; },
  enumerable: false          // 讓它不出現在 Object.keys 與 for...in
});

// 寫法三：class（最接近 Java / C# 的心智模型）
class User {
  #age = 0;                  // ES2022 真私有欄位
  get age() { return this.#age; }
  set age(v) {
    if (v < 0) throw new RangeError("年齡不可為負數");
    this.#age = v;
  }
}

g. Java 與 C# 的對照寫法，看一次就知道差別在哪：

// Java：一定要在 class 裡，而且 getter / setter 是「方法」，呼叫要加括號
public class User {
    private int age;                              // 私有欄位
    public int getAge() { return age; }           // Getter
    public void setAge(int age) {                 // Setter（含驗證）
        if (age < 0) throw new IllegalArgumentException("年齡不可為負數");
        this.age = age;
    }
}
// 使用：user.setAge(25);  int a = user.getAge();

// C#：語言把 getter / setter 包成「屬性（Property）」，用起來像欄位不用加括號
public class User {
    private int _age;
    public int Age {
        get => _age;
        set {
            if (value < 0) throw new ArgumentOutOfRangeException(nameof(value));
            _age = value;
        }
    }
}
// 使用：user.Age = 25;  int a = user.Age;

# Python：用 @property 裝飾器，用起來也像欄位
class User:
    def __init__(self):
        self._age = 0

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        if value < 0:
            raise ValueError("年齡不可為負數")
        self._age = value
# 使用：user.age = 25   a = user.age
