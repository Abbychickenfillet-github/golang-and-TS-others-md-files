① Stack Frame push/pop 動畫（counter() 閉包例子）

先釐清一個容易誤會的地方：下面方塊裡的「counter()」「(anonymous)()」，代表的是這次呼叫產生的 Stack Frame（呼叫紀錄），不是把函式本體當成一個 primitive 值塞進 Stack。函式在 JS 裡本身是一種物件（Function 是 Object 的一種）：它的程式碼定義、之後可能形成的 closure 環境，實際存放位置是 Heap，不是 Stack。被呼叫的當下，Stack 上 push 的只是這次呼叫的執行紀錄——裡面裝的是這次呼叫的參數、區域變數（可能是 primitive 值，也可能是指向 Heap 物件的位址）、以及 return 要跳回哪一行的返回位址，跟「函式定義本身放在哪裡」是完全獨立的兩件事。 

function counter() {
  let count = 0;
  return function () {
    return ++count;
  };
}
const next = counter();
next(); // 1
📚 Stack
🗄️ Heap
