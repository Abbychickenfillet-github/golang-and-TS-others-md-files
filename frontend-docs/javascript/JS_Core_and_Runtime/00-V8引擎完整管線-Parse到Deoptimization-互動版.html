為什麼要分 4 張圖？

程式碼進 V8 之前有兩種不同起點——原生 JS（直接是標準 JS）vs React／TSX（要先經過 Babel/tsc 轉譯）；進了 V8 之後，同一段程式碼在生命週期裡又會經歷冷路徑（Ignition 直譯）跟熱路徑（TurboFan 優化）兩種狀態。兩個維度交叉＝ 4 條路徑。點下面按鈕切換，右側會同步顯示「跟基準線（圖①）比起來，這條路徑多了 / 換了什麼」。
