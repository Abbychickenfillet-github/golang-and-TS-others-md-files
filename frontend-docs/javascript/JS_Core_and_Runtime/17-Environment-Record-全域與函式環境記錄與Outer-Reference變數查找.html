重點整理

(a) Environment Record（環境記錄）是 ECMAScript 規格裡用來儲存「識別碼（identifier）→ 值」對照表的內部結構。JS 引擎每進入一個作用域（全域、函式、區塊）就建立一個，變數與函式宣告都記在裡面。

(b) 每個 Environment Record 都帶一條 Outer Reference（外部環境連結），指向外層的 Environment Record。全域那一層的 Outer Reference 是 null，這就是作用域鏈（scope chain）的終點。

(c) 範例程式與引擎建出來的結構如下（程式碼為 Gemini 原例）：

let name = "Alice";
const age = 25;

function greet() {
  let message = "Hello";
  console.log(message + " " + name);
}

greet();

┌─ Function Environment Record（執行 greet() 時建立）─┐
│ message   : "Hello"                                 │
│ arguments : { length: 0 }                           │
│ this      : window 或 undefined（看嚴格模式）          │
│ Outer ────┐                                         │
└───────────┼─────────────────────────────────────────┘
            ▼
┌─ Global Environment Record ─────────────────────────┐
│ name  : "Alice"                                     │
│ age   : 25                                          │
│ greet : <function>                                  │
│ Outer : null                                        │
└─────────────────────────────────────────────────────┘

(d) 變數查找（resolve identifier）的流程：引擎先在目前的 Environment Record 找這個名字，找不到就沿著 Outer Reference 往外一層找，一路找到全域，還找不到才丟出 ReferenceError。以 console.log(message + " " + name) 為例：message 在 greet 自己的記錄就找到，name 要靠 Outer Reference 跳到全域才找到。

(e) Outer Reference 指向哪裡是在函式「定義」的位置決定的，不是呼叫的位置，這就是詞法作用域（Lexical Scope）。即使 greet 被丟到別處去呼叫，它的 Outer 仍然指回當初定義它的那一層。閉包能活下來也是同一個原因：內層函式握著外層 Environment Record 的參照，外層記錄就不會被回收（見 閉包-createCounter與Heap上的Environment-Record）。

(f) ⚠️ 存疑／更正：Gemini 的範例把全域的 name、age、greet 畫成同一張表，這是教學簡化。依規格，Global Environment Record 其實由兩部分組成：Object Environment Record（綁到 globalThis，裝 var 與函式宣告）和 Declarative Environment Record（裝 let、const、class）。所以 let name 與 const age 不會變成 window.name、window.age 的屬性，而 function greet 會變成 window.greet。另外 this 在規格中是 Function Environment Record 的 ThisValue 內部欄位，不是一般綁定，這裡只當概念看待。

使用者：舉例

Gemini：以 JavaScript 執行以下程式碼為例，JavaScript 引擎會建立不同的 Environment Record 來儲存這些資訊。

  1. 全域作用域（Global Environment Record）：name "Alice"（未初始化 → 賦值）、age 25、greet 為函數參照。
  2. 函式作用域（Function Environment Record，執行 greet() 時建立）：message "Hello"、arguments { length: 0 }、this 為 window 或 undefined（視嚴格模式而定）、外部環境連結（Outer Reference）指向全域 Environment Record。

變數尋找的過程：找 message 在 greet 的記錄就找到 "Hello"，找 name 在 greet 的記錄找不到，透過 Outer Reference 往外找，最後在全域記錄找到 "Alice"。
