申論題

  1. 什麼時候該在筆記裡用數學模式、什麼時候不該？請給一個可以直接照著做的判準。

    參考方向：(1) 判準一句話：只有在寫「真的需要數學排版」的東西時才進數學模式——分數、上下標、根號、求和符號、矩陣、希臘字母。(2) 程式碼、識別字、布林值、檔名一律用反引號，因為它們要的是等寬字體而不是數學斜體，而且反引號在任何 Markdown 環境都能正確渲染，數學模式則依賴外掛。(3) 純說明文字什麼都不用加。(4) 唯一需要 \text{} 的場合是「已經在數學式裡了，但要插一段人看的文字」，例如 $T_{\text{avg}} = n/2$。(5) 實務提醒：Obsidian 的 $ 對前後空白敏感，而且在表格裡容易跟 | 打架，所以表格儲存格盡量避免數學模式。

重點整理

一、那串符號到底是什麼（a–c）

(a) $ 是「進入數學模式」的開關。單個 $...$ 是行內公式、$$...$$ 是獨立成行的公式。這不是 Markdown 原生語法，是 Obsidian、GitHub、Jupyter 等環境掛上 MathJax 或 KaTeX 之後才支援的。

(b) \text{} 是 LaTeX 的專用指令，用來「在數學公式中顯示一般字型的文字」。因為數學模式預設會把字母當變數排成斜體（true 會被排成 $t\cdot r\cdot u\cdot e$ 四個變數相乘的樣子），\text{true} 才會讓它維持正常的直立字體。

(c) 所以 $(\text{true})$ 的意思是「在數學模式裡放一個括號和一段正常字體的 true」——技術上沒有錯，但用在一份講程式碼的筆記裡是殺雞用牛刀而且反而變醜。

二、該怎麼改（d–f）

(d) 要呈現程式碼或布林值，直接用反引號：

❌ `1 == "1"` $(\text{true})$
✅ `1 == "1"`（`true`）
✅ `1 == "1"` (true)

(e) 括號要不要留？要留。改的時候是把 $(\text{true})$ 整串換成 (true)，括號本來就是原本要呈現的內容，不要連括號一起刪掉。

(f) 判準一句話：只有真的在寫數學（分數、上下標、求和符號、矩陣）才進數學模式；其餘一律用反引號或純文字。

情境 該用什麼 例子
程式碼、識別字、布林值 反引號 `Object.is`、`true`
純粹的說明文字 什麼都不用 (true)
真的在寫數學 數學模式 $O(n \log n)$、$\frac{a}{b}$
數學式裡要插一段中文或英文單字 \text{} $T_{\text{avg}} = \frac{n}{2}$

[!warning] Obsidian 的額外坑
Obsidian 的數學模式對 $ 前後的空白很敏感，而且 $ 在表格裡容易跟 | 打架。在表格儲存格裡盡量不要用 $...$，這也是 Abby 那張表格會炸開的原因之一。
