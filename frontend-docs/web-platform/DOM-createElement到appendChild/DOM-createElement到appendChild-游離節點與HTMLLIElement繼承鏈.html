3. HTMLLIElement 是什麼：介面繼承鏈

HTMLLIElement的全名是 HTML List Item Element，也就是 <li>（list item，清單項目）專屬的介面。 名字裡有兩個 L，第一個 L 是 HTML 的 L，第二個 L 是 List 的 L。

3-1. 為什麼每個標籤都有自己的介面

HTML 規格用 Web IDL（Interface Definition Language，介面定義語言）替每一種標籤宣告一個介面。 document.createElement('li') 會拿標籤名去查規格的對照表，查到 li 對應 HTMLLIElement，就建立一個屬於這個介面的物件。

介面在 JS 裡長成一個建構函式加一個 prototype 物件，彼此用原型鏈串起來，概念上就像 class HTMLLIElement extends HTMLElement。
瀏覽器不讓你直接 new HTMLLIElement()（會丟 TypeError: Illegal constructor），一定要透過 createElement 或 HTML parser 產生。

3-2. 繼承鏈：點每一層看它提供什麼

平常寫的 appendChild、className、addEventListener 都是從上面幾層繼承來的，HTMLLIElement 自己只多了一個 value，所以平常感覺不到它的存在。 標籤右邊的綠色＝本頁用 hasOwnProperty 實測確認「這個屬性就定義在這一層」。

3-3. 標籤名對應的介面（本頁即時實測）

createElement 傳入規格對應的介面本頁實測 constructor.name白話

文字節點走另一條鏈：Text → CharacterData → Node → EventTarget → Object。 它沒有 Element 這一層，所以文字節點沒有 className、querySelector，也不能再掛子節點。

4-1. 為什麼 document.querySelector 找不到游離節點

querySelector 從呼叫它的節點出發，以深度優先、前序（tree order）走訪子孫節點。 從 document 出發走不到沒有父節點的 newEl，從 newEl 自己出發就走得到它底下的 span。

var newEl = document.createElement('li');
newEl.innerHTML = '<span>quinoa</span>';
document.querySelector('span');  // null
newEl.querySelector('span');     // <span>quinoa</span>
第 1 行在記憶體造一個 li，第 2 行在它裡面塞一個 span。
第 3 行從整份文件往下找 span，走不到 newEl 所以回傳 null。
第 4 行從 newEl 自己往下找，第一個子孫就是 span。

4-2. 為什麼先在記憶體組好再一次掛上去

節點還游離時改它，瀏覽器不需要重新排版。 先在記憶體把整包組好，最後一次 appendChild，版面只重算一次。 同一顆節點 appendChild 到第二個父節點時會從原本位置搬走，因為一個節點只能有一個 parentNode。

8. 自我測驗

8-1. 填空

  1. createElement('li') 回傳物件的介面名稱是
    HTML List Item Element。
  2. 游離節點的 parentNode 是
    還沒有父節點。
  3. 判斷節點是否接到 document 的屬性是
    定義在 Node 那一層。
  4. appendChild 定義在原型鏈的 那一層
    所以文字節點也有 appendChild（但對文字節點呼叫會丟錯）。
  5. addEventListener 定義在
    鏈的最上層（Object 之前）。

8-2. 是非題

  1. createElement 執行完，節點就會出現在畫面上。
    要等 appendChild 接進 DOM 樹才會畫出來。
  2. 游離節點也可以 addEventListener。
    它是完整物件，掛進樹之後事件照樣會觸發。
  3. 同一顆節點 appendChild 到第二個父節點，會複製一份。
    會搬家；要複製得用 cloneNode。
  4. document.createElement('foo') 回傳 HTMLUnknownElement。
    規格裡查不到的非自訂元素名稱都歸到 HTMLUnknownElement。
  5. 可以用 new HTMLLIElement() 直接建立 li。
    會丟 TypeError: Illegal constructor。
  6. 文字節點的原型鏈裡沒有 Element。
    Text → CharacterData → Node → EventTarget。

8-3. 申論題

  1. 為什麼 newEl.querySelector 找得到 span，document.querySelector 卻找不到？
    querySelector 從呼叫者出發走訪子孫。newEl 沒有父節點，不在 document 的子孫裡，所以從 document 出發走不到；從 newEl 出發，span 就是它的子節點。
  2. 說明 HTMLLIElement 繼承鏈每一層各提供什麼。
    HTMLLIElement 提供 li 專屬的 value。HTMLElement 提供所有 HTML 元素共用的 hidden、innerText、style。Element 提供 className、id、querySelector、setAttribute。Node 提供 parentNode、appendChild、isConnected 這類樹狀結構操作。EventTarget 提供 addEventListener。
  3. 為什麼建議先在記憶體組好節點，再一次 appendChild？
    游離節點不參與版面計算，修改它不會觸發 reflow。全部組好後一次掛進樹，版面只需重算一次。
