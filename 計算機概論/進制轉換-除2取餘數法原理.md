# 進制轉換與「除 2 取餘數法」原理

## 重點整理

### 為什麼「一直除以 2、餘數倒過來」就是二進制?

把十進制數字 N 轉成二進制時,常用<mark style="background: #FFF3A3A6;">「除 2 取餘數法」</mark>:不斷除以 2、記下每次餘數,最後把餘數<mark style="background: #FF5582A6;">由下往上(從最後一個餘數讀回第一個)</mark>排列就是答案。

關鍵疑問:為什麼<mark style="background: #ADCCFFA6;">第一個餘數是最低位元(LSB)、最後一個餘數是最高位元(MSB)</mark>?

原理來自<mark style="background: #ADCCFFA6;">多項式除法(Polynomial Division)</mark>。任何十進制數字 N 都可以寫成以 2 為底的多項式:

```
N = aₙ·(2ⁿ) + … + a₂·(2²) + a₁·(2¹) + a₀·(2⁰)
```

其中每個係數 aᵢ 只會是 0 或 1,就是二進制的各個位元。

當你把這個多項式<mark style="background: #BBFABBA6;">除以 2</mark> 時:

- 含有 2¹、2²、…、2ⁿ 的項都能被 2 整除 → 變成商。
- 只有<mark style="background: #FFF3A3A6;">最低次的 a₀·(2⁰) = a₀ 無法被整除 → 它就是餘數</mark>。

所以<mark style="background: #BBFABBA6;">第一次相除的餘數,必定對應 2⁰ 這一項,也就是最低位元</mark>;接著對商繼續除 2,下一個餘數對應 2¹…依此類推。等除到商為 0,<mark style="background: #FF5582A6;">最後一個餘數對應最高次幂,就是最高位元</mark>。這就是「餘數要倒過來讀」的數學根據。

### 多項式除法基礎

不論整數或多項式除法,都符合同一個基本關係:

```
被除式 = 除式 × 商式 + 餘式
f(x) = g(x)·q(x) + r(x)
```

<mark style="background: #FF5582A6;">重要規則(次數限制):餘式 r(x) 的最高次數一定要小於除式 g(x) 的最高次數。</mark>例如除式是二次方(x²),餘式最多只能是一次方(ax+b)或常數;餘式為 0 代表「整除」。

兩種主要計算法:

| 方法 | 適用 | 特點 |
|---|---|---|
| 長除法 Long Division | 任何多項式相除 | 最通用、最直覺;降冪排列,缺項補 0,逐步消去最高次項 |
| 綜合除法 Synthetic Division | 除式為一次式 (x − c) | 只抓係數做加減乘,計算量大幅減少,適合快速求因式或求值 |

> [!tip] 一句話總結:十進制→二進制的「除 2 取餘」其實就是把 N 看成以 2 為底的多項式,反覆做多項式除法、一層層把係數(位元)從低位到高位剝出來。任何進制轉任何進制都是同理(除以目標底數即可)。

### 小數部分怎麼轉：「乘 2 取整法」（除 2 取餘數法的鏡像，2026-09-28 追加）

整數部分用<mark style="background: #FFF3A3A6;">除 2 取餘數</mark>、由下往上讀；<mark style="background: #ADCCFFA6;">小數部分</mark>剛好反過來，要用<mark style="background: #BBFABBA6;">乘 2 取整數</mark>、由上往下讀：

```
0.1 × 2 = 0.2   → 取整數 0
0.2 × 2 = 0.4   → 取整數 0
0.4 × 2 = 0.8   → 取整數 0
0.8 × 2 = 1.6   → 取整數 1（留下小數 0.6 繼續乘）
0.6 × 2 = 1.2   → 取整數 1
0.2 × 2 = 0.4   → 取整數 0（回到第 2 步的 0.2，開始循環）
```

十進制 `0.1` 轉成二進制是 `0.0001100110011...`（`0011` 無限循環），跟十進制的 `1/3 = 0.333...` 是同一種「有限小數在另一個進位制下變無限循環」的現象。

<mark style="background: #FF5582A6;">陷阱：不是每一次都會終止</mark>。整數轉二進制一定會在有限步驟內除到商為 0；但小數轉二進制不一定會乘到剩下 0，很多十進制小數（包含最常見的 `0.1`、`0.2`）在二進制下都是無限循環小數，這正是 `0.1 + 0.2 !== 0.3` 這類 [[numeric-precision-safety|浮點數精度問題]] 的根源，兩者是同一件事的一體兩面。

> [!tip] 一句話對照：整數部分「除 2、由下往上讀餘數」；小數部分「乘 2、由上往下讀整數」。兩者都是把數字拆成 2 的次方展開式，只是整數在剝正次方項、小數在剝負次方項。
