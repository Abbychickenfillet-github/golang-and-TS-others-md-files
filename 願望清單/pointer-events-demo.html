這台機器被瀏覽器怎麼認定

要觀察的重點 用滑鼠畫的時候 pressure 會是固定值，用壓感筆畫的時候它會隨力道在 0 到 1 之間變動，筆跡粗細也會跟著變。 另外看右邊那塊：在變形筆電上 (pointer: fine) 與 (any-pointer: coarse) 會同時為 true，這就是為什麼不能只靠 CSS 媒體查詢判斷使用者當下在用觸控。

為什麼畫布要寫 touch-action: none

瀏覽器預設會把手指的拖曳解讀成捲動頁面，這樣 pointermove 會在捲動開始的瞬間被取消，你就畫不出線。touch-action: none 的意思是「這個元素上的觸控手勢全部交給我自己處理，瀏覽器不要插手」，所以手指才畫得動。
