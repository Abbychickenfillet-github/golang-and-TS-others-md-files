## 為什麼建議寫在 `createCounter` 裡面？

```javascript
function createCounter(buttonId) {
    let count = 0;
    const button = document.getElementById(buttonId);  // ← 這裡
    return function inner() {
        count++;
        button.textContent = `Counter: ${count}`;
    };
}
```

主要有三個原因：

### 1. 每個計數器綁定「自己的」按鈕

`createCounter("counter")` 和 `createCounter("counter2")` 會各自建立 closure，裡面的 `button` 會被記住：

- `counter` → 永遠指向 `#counter`
- `counter2` → 永遠指向 `#counter2`

這樣 `inner()` 被點擊時，不用每次再判斷要改哪個按鈕。

### 2. 只查一次 DOM，不用每次點擊都查

| 寫法 | 行為 |
|------|------|
| 寫在 `createCounter` 內 | 建立計數器時查一次 |
| 寫在 `inner()` 內 | 每次點擊都查一次 |

對這個小例子差異不大，但習慣上會把「不會變的東西」在建立時就取得。

### 3. 和 `count` 一起被 closure 記住

```javascript
function createCounter(buttonId) {
    let count = 0;           // 被 closure 記住
    const button = ...;      // 也被 closure 記住
    return function inner() {
        count++;               // 用記住的 count
        button.textContent = ...;  // 用記住的 button
    };
}
```

`count` 和 `button` 都是這個計數器需要的資料，一起放在 factory 裡，結構比較清楚。

你原本的寫法：


## Cursor
你現在的 `count` 只在 JavaScript 裡，HTML 上的 `<button>Counter</button>` 不會自動更新。要用 JS 把變數「寫進」按鈕文字。

## 做法：改 `button.textContent`

按鈕上顯示的文字，可以用 JavaScript 的 `textContent` 來改：

```javascript
function createCounter(buttonId) {
    let count = 0;
    const button = document.getElementById(buttonId);

    return function inner() {
        count++;
        button.textContent = `Counter: ${count}`;  // ← 把變數插進去
    };
}
```

`${count}` 是 template literal，會把變數的值插進字串裡。
