## Cursor

要啟動的是子目錄裡的 Vue + Vite 專案 `happy-vue-playground`（依賴看起來已經裝過了）。在 repo 根目錄 `c:\coding\happy-vue` 直接跑指令不會生效。

在終端機執行：

```sh
cd happy-vue-playground
npm run dev
```

終端機會印出本機網址，通常是 **http://localhost:5173**。用瀏覽器打開即可；改 `src` 底下的檔案會熱更新。

若還沒裝依賴，或換了機器，先執行一次：

```sh
cd happy-vue-playground
npm install
npm run dev
```

Node 版本要符合 `package.json`：`^22.18.0` 或 `>=24.12.0`。
