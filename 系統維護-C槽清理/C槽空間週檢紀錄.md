## 備註

- 本 session 只能讀到已連接資料夾(Abby-notes)所在磁碟的掛載資訊，無法直接讀取 Windows C 槽本身的 `df` 數據，此處用掛載點所在磁碟作為代理參考(最新一次：共 476G，已用 464G，可用 13G，使用率 98%)。
- 趨勢：7/19 可用 68G → 7/26 可用 55G → 8/2 可用 17G → 8/9 可用 8.2G → 8/16 可用 32G → 9/6 可用 15G → 9/20 可用 13G。8/16 清理後釋出的空間在三週內被吃掉約 17GB，之後兩週又再少 2GB，代表這兩週並沒有做清理，空間持續被 Docker build cache 與只長不縮的 vhdx 慢慢啃掉。
- 若要精確得知 C 槽實際可用空間，請在 CMD 執行：

```
fsutil volume diskfree C:
```

- 判斷標準：可用 < 30GB → ⚠️ 該清理了；可用 >= 30GB → ✅ 空間充足。
