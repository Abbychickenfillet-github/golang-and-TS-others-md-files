申論題

  1. 比較用 Syncthing 同步 Obsidian vault 與用 Google Drive／Obsidian Sync 的優缺點，並說明你會怎麼選。

    參考方向：(1) Syncthing 優點：完全免費（除 iOS 客戶端）、沒有容量上限、端對端加密且檔案只存在自己裝置上、隱私最好。(2) Syncthing 缺點：兩台裝置必須「同時在線」才會同步，手機容易被省電機制殺掉背景程序；沒有雲端當中介，所以裝置都關機時就完全不會同步；多裝置同時編輯會產生 sync-conflict 副本。(3) 雲端方案優點：非同步、隨時可同步、有版本歷史、設定簡單。缺點：要錢、廠商技術上讀得到內容。(4) 選擇建議：重視隱私與成本、裝置常一起開機就選 Syncthing；需要跨時區、裝置很少同時開機、或不想處理衝突就選雲端方案。(5) 可補充風險控管：開啟 File Versioning、忽略 .obsidian/workspace.json、養成「編輯前先確認另一台同步完成」的習慣。

    參考方向：(1) 觀念錯誤：Möbius Sync 是 iOS／iPadOS 專屬的客戶端，Android 上根本沒有這個 App，所以找不到是正常的。(2) 為什麼 iOS 才需要它：Apple 的沙盒機制不允許 App 隨意讀寫其他 App 的資料夾，所以要有專門開發的客戶端，並用一次性內購解鎖「存取其他 App 沙盒」的能力。(3) Android 的正確做法：直接從 Google Play 安裝 Syncthing-Fork，免費、開源、沒有任何容量限制。(4) 順帶提醒：不要跟 Sync.com 搞混，那是另一家賣雲端空間的廠商。(5) 若對方確實是在 iOS 上找不到付費按鈕：那是因為解鎖流程要「觸發限制」才會跳出，可以試著 Add Folder 選一個外部資料夾，或直接下載獨立的 Möbius Sync Pro。

Syncthing P2P 檔案同步——Obsidian Vault 跨裝置同步設定

[!info]- 📍 為什麼要記這個
Obsidian 官方的 Obsidian Sync 要訂閱費，而 vault 本質上只是一堆 .md 純文字檔加附件——只要能把資料夾同步過去，手機上的 Obsidian 就能直接打開。Syncthing 正好解決這件事，而且不經過任何雲端。
關聯：Obsidian-語音筆記與GoogleDocs銜接限制 講的是「內容怎麼進 vault」，這篇講的是「vault 怎麼在裝置之間流動」。

本篇重點 (a)–(l)，共 12 個。

一、Syncthing 是什麼，跟雲端硬碟差在哪

a. Syncthing 是開源的 P2P（Peer-to-Peer，點對點）檔案同步工具。它不提供任何雲端空間，檔案是從你的電腦「直接」傳到你的手機，中間不落地到第三方伺服器。

Syncthing Google Drive／Dropbox 這類雲端
檔案存在哪 只存在你自己的裝置上 存在廠商的伺服器
容量上限 你的硬碟有多大就多大 依方案付費
需要裝置同時開機嗎 需要，兩台都要在線才會同步 不需要，雲端隨時在
隱私 端對端加密，廠商看不到內容 廠商技術上讀得到
費用 免費開源（iOS 客戶端除外） 超過免費額度要付費

b. 最容易搞混的一點：搜尋時會看到 「Sync.com」（賣 1TB／2TB／10TB 雲端空間的廠商），那跟 Syncthing、跟 Möbius Sync 是完全不同的服務，別買錯。

二、各平台該裝哪一個

c. 這是最花錢也最容易踩雷的一格：

平台 該裝什麼 費用
Windows／macOS／Linux Syncthing 官方版（網頁介面操作） 完全免費
Android（含紅米平板） Syncthing-Fork（Google Play 上的社群維護版） 完全免費、無容量上限
iOS／iPadOS Möbius Sync（第三方客戶端，內部用 Syncthing 引擎） 免費版只有 20MB 且僅限 App 自己的沙盒，需一次性內購解鎖

[!danger]+ 別在 Android 上找付費選項
d. Android 完全不需要付費。Android 版 Syncthing 沒有容量限制，本身就是免費開源的完整軟體。Möbius Sync 是 iOS 專屬的客戶端，因為 Apple 的沙盒（sandbox）機制不允許 App 隨意讀寫其他 App 的資料夾，才需要額外開發與付費解鎖。

[!question]+ 「Möbius Sync 沒有跳出付費按鈕」怎麼辦
e. Möbius Sync 的解鎖不是一個獨立按鈕，而是「觸發限制時才跳出」。原因有二：（1）免費額度還沒用完——只要沙盒內檔案總量沒超過 20MB，系統不會催你付費；（2）還沒去碰受限功能——要解鎖「存取其他 App 的沙盒」（例如同步 Obsidian 的外部資料夾），得實際去點 Add Folder 並選一個外部資料夾，權限被擋下時購買流程才會啟動。
f. 另一條路是直接下載獨立的 Möbius Sync Pro（另一個 App），功能與內購解鎖後完全相同。

三、配對流程：ID 不要貼成自己的

g. 最常見的失敗原因：把自己裝置的 ID 貼進自己的設定裡。正確方向是交換——在電腦上輸入「手機的 ID」，在手機上接受「電腦的邀請」。

h. 裝置 ID（Device ID）長這樣：一長串大寫英數字，每 7 碼用一個橫槓隔開，例如 3PXANYP-M6L7EHF-Z4L9AHD-2P6J3E4-G3H7K4J-F5R6D7A-L2G9Y4P-B3H6N2D。格式不對系統會直接擋下來，所以貼錯不會靜默失敗，這點還算友善。

[手機] 複製自己的 Device ID
   │
   ▼
[電腦] Syncthing 網頁介面 → 新增遠端裝置 → 貼上「手機的」ID
   │
   ▼
[手機] 跳出通知 → 接受
   │
   ▼
兩台裝置互相看得見了（狀態顯示 Connected）

四、加入資料夾：不用先手動建好

i. 不需要事先在另一台建好同名資料夾。Syncthing 會自動建。只要在其中一邊設定、另一邊按「接受」即可：

  • 從電腦推出去：電腦 → Add Folder → 選現有資料夾（例如 Obsidian vault）→ Sharing 分頁勾選手機 → 手機收到通知按接受 → 手機自動長出同名資料夾。
  • 從手機推出去：手機 Syncthing-Fork → Add Folder → 選資料夾 → 分享給電腦 → 電腦按接受。

j. 把 Obsidian vault 加進來之後，手機端的 Obsidian 只要用「開啟現有 vault」指向那個同步資料夾，就能直接編輯，改動會自動流回電腦。

[!warning]+ ⚠️ Obsidian ＋ Syncthing 的已知風險（對話沒提到，但很重要）
- 兩台同時編輯同一個檔案會產生衝突副本（檔名會多出 sync-conflict 字樣）。習慣是「編輯前先確認另一台已同步完成」。
- 建議在 Syncthing 的資料夾設定裡忽略 .obsidian/workspace.json 這類會頻繁變動的介面狀態檔，否則兩台會一直互相覆蓋。
- 開啟檔案版本控制（File Versioning），誤刪時還救得回來。

五、手機老是顯示「斷線 Offline」

k. Syncthing 要同步必須同時滿足三件事：兩台都開著 App、兩台都連著網路、兩台找得到彼此。手機顯示 Offline 通常是被系統省電機制殺掉了背景程序。

l. Android 上的三個設定（依重要性排序）：

設定 位置 做什麼
停用電池最佳化 系統設定 → 應用程式 → Syncthing-Fork → 電池 → 選「不受限制／不最佳化」 最關鍵。Android 為了省電會自動關掉背景 App，這一項不改其他都白搭
開啟背景同步 Syncthing-Fork App 內 → 設定 → Background Sync 讓它常駐在背景
允許行動網路 Syncthing-Fork → 設定 → 連線／資料用量 → Use Mobile Data 不在同一個 Wi-Fi 也想同步時才需要開；同一個 Wi-Fi 下連線品質最好
