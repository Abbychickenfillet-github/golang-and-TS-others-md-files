重點整理

(a) SPA（Single Page Application，單頁應用程式）瀏覽器一次下載 HTML、JavaScript、CSS。之後操作只透過 JS 向 API 取資料並動態更新畫面，不重新載入整頁。
(b) document.cookie 由 JS 讀寫document.cookie 是瀏覽器提供的屬性，JS 可讀取或設定 cookie。cookie 用來存小量資料，常見用途是身分驗證與偏好。
(c) 兩者負責的功能不同SPA 資料更新＝呼叫 API 取新資料再渲染；document.cookie＝在瀏覽器存小量狀態。「都用 JS」是實作手段相同，但不是同一個概念。
(d) ⚠️ 與 Docker 無關對話中把 cookie 誤聽成 Docker（語音輸入），Gemini 也只回「Docker 用來打包執行應用程式」。Cookie 不屬於 Docker。
