d. 申論題（面試）

1. 請說明為什麼 origin: "*" 搭配 Cookie 登入的即時系統不安全，以及你會怎麼改。

WebSocket 不受 CORS 約束，所以靠 Cookie 認證的連線若不檢查 Origin，任何網站的腳本都能讓使用者的瀏覽器帶著登入狀態連進來，這就是跨站 WebSocket 劫持。

改法：a. cors.origin 改成明確白名單。b. 用 allowRequest 在握手階段檢查 Origin。c. 真正的授權要靠連線時驗證 token 或 session，不能只靠 Origin，因為非瀏覽器的客戶端可以偽造標頭。

2. 你的專案有用 Express 嗎？請說明 Express 與 Node http 的關係。

本專案是 Next.js，Route Handler 由 Next 內部的 server 處理，我沒有自己建 http server。Express 是建在 Node http 之上的框架，express() 回傳 (req, res, next) 函式，app.listen 只是 http.createServer(app).listen 的語法糖。需要掛 WebSocket 時我會自己建 httpServer。
