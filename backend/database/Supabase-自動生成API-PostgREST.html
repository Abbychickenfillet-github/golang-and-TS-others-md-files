# Supabase 自動生成 API（PostgREST）

本篇重點 a–c，共 3 個

## 重點整理

(a) Supabase 不需要省略：傳統開發要手寫 Express / FastAPI Server、SQL 查詢與 API 路由，這些 CRUD 工作由 Supabase 的 PostgREST（把 PostgreSQL 資料表自動轉成 REST API 的引擎）處理。

(b) 使用方式：前端或專案安裝 `@supabase/supabase-js`，再用 Supabase SDK 對資料庫做查詢或更新。

(c) 客製化複雜邏輯：單純 CRUD 做不到的業務邏輯，再搭配 Next.js API Routes / Server Actions 或 Supabase Edge Functions 寫自訂後端。
