重點整理

HeidiSQL：匯出「查詢結果」≠「SQL 匯出」

「SQL 匯出」功能不能用來匯出 SELECT 跑出來的結果網格——它是用來匯出資料庫結構與資料表內容（資料庫物件）的。

要匯出底部「結果」標籤頁看到的查詢結果，正確做法是在結果網格上按右鍵 →「匯出網格行（Export grid rows）」：

  1. 在「查詢」頁執行 SELECT，結果顯示在底部「結果」區。
  2. 要部分匯出就拖曳選取幾行；要全部則不必選。
  3. 在結果網格按右鍵 → 匯出網格行。
  4. 設定格式：CSV（易用 Excel/程式讀）或 HTML/Excel；勾選「包含列標題 Include column headers」（強烈建議，否則不知欄位是什麼）。

ALTER TABLE：新增欄位 ADD COLUMN

語法：ALTER TABLE [表名] ADD COLUMN [欄名] [型態] [約束] [位置];

-- 新增 VARCHAR 欄位,放在 price_per_unit 之後
ALTER TABLE `future_sign`.`electricity_calculation_rule`
ADD COLUMN `spec_name` VARCHAR(50) NULL AFTER `price_per_unit`;
  • AFTER 欄名 指定新欄位插在哪個欄位之後。
  • 用 VARCHAR(n) 存放文字規格說明（例如 0.5KW、110V15A）。

ALTER TABLE：欄位改名 CHANGE COLUMN

-- 把 amper 改名為更語意化的 spec_name
ALTER TABLE `future_sign`.`electricity_calculation_rule`
CHANGE COLUMN `amper` `spec_name` VARCHAR(50) NULL DEFAULT NULL;

CHANGE COLUMN 改名時必須重寫完整型態定義（VARCHAR(50) NULL DEFAULT NULL），不能只給新名字。

INSERT INTO ... VALUES 的欄位順序陷阱

使用 INSERT INTO 表 VALUES (...) 省略欄位列表時，VALUES 內的值必須與資料表「當前的欄位順序」完全一致，不能缺漏或錯位。所以每次 ALTER TABLE 改了欄位（新增/改名/換位）後，舊的 INSERT 語句都要跟著重排。
（較安全的寫法是明寫欄位列表：INSERT INTO 表 (col1, col2, ...) VALUES (...)。）

補充：命名建議

描述「品項/規格」的欄位，避免含糊的 electricity_name，改用中性具體的 item_name／rule_name／spec_name，並讓「費用規則表」與「實際申請表」職責分離，用 rule_id/item_id 外鍵關聯。

追加 2026-07-27：開啟後只看到查詢視窗、點不開資料表

症狀：開啟 HeidiSQL 後只顯示 SQL 查詢紀錄（如 SELECT CONNECTION_ID() 這類連線時的初始指令），左側沒有資料庫樹狀選單可以點資料表。

常見原因與排解：

  1. 導覽列（左側）被隱藏或縮小——檢查左上角「資料庫選單」標籤是否被收起，或側邊緣是否有可拉開的箭頭。正常應該會看到資料庫（如 future_sign_stage）出現在左側樹狀目錄。
  2. 未點選具體資料表——SQL 查詢視窗本身不會顯示表格內容，必須在左側展開資料庫後雙擊資料表（如 users、events），右側才會切出「基本資訊 / 結構 Structure / 資料 Data」分頁，「資料」分頁才是實際內容。
  3. 按 F5 重新整理，確保資料庫物件列表已正確載入。

判斷連線是否正常的線索：若視窗中已出現 USE future_sign_stage; 且能執行，代表連線本身沒問題，純粹是介面停在「查詢」分頁而非「瀏覽資料表」分頁。

使用者： 我們要怎麼在 HeidiSQL 匯出底下搜尋結果？

Gemini： 在 HeidiSQL 中不能用「SQL 匯出」功能來匯出查詢結果（SELECT 後底下的表格）——「SQL 匯出」是用來匯出資料庫結構和資料表內容（資料庫物件）。要匯出底部「結果」標籤頁的查詢結果，須用「匯出網格行（Export grid rows）」：①執行 SELECT，結果顯示在底部；②要部分匯出就拖曳選取，全部則不選；③在結果網格按右鍵 →「匯出網格行」；④設定格式（CSV 易於 Excel/程式讀，或 HTML/Excel），檔名，勾選「包含列標題」（強烈建議）。

使用者： 也可以幫我新增 amper 這個 column，用來輔助說明品項的名稱。

Gemini： 新增 VARCHAR 欄位最合適。ALTER TABLE … ADD COLUMN \amper` VARCHAR(50) NULL AFTER `price_per_unit`;。注意用INSERT INTO table VALUES (...)` 省略欄位列表時，VALUES 的值必須與資料表當前欄位順序完全一致。
