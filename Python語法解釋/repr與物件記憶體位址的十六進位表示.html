Python repr() 是什麼？物件記憶體位址為何用十六進位顯示

與 [[進位制-二進制-十六進制-Bytes與RGB]] 相關：那篇從硬體／CPU 角度講「為什麼到處是十六進制」，這篇是同一個換算規則（1 個 16 進位字元＝4 bits）在 Python 語言層級的實際案例——repr() 印出物件記憶體位址時，就是用這套規則顯示成 0x1077f2f10 這種格式，兩篇對照看才知道「為什麼 debug 訊息長這樣」的完整脈絡。

重點整理

本篇重點 (a)–(c)，共 3 個。

(a) repr 是什麼

repr 是「representation（表示法）」的縮寫，repr() 是 Python 內建函式，用來回傳一個物件的「官方」字串表示形式。這個字串的設計目標是盡可能明確且無歧義，主要用途是讓開發者在除錯（debugging）時能清楚知道物件的內部狀態。

(b) 為什麼自訂類別的 repr() 會印出十六進位位址

當建立一個自訂類別的物件（例如 JustAnExample），且沒有特別定義它的顯示方式（沒有覆寫 __repr__）時，Python 預設的 repr() 輸出行為，是印出該物件的模組與類別名稱，以及它在記憶體中的實體位址，例如 <__main__.JustAnExample object at 0x1077f2f10>。Python 會自動以十六進位（Hexadecimal）形式顯示這個記憶體位址，因為十六進位能比十進位更簡潔地對應底層的二進位資料。

(c) 1 位十六進位＝4 bits，1 byte 要用 2 位十六進位

1 個 16 進位數字＝4 個 bits（位元）：二進位中 4 個 bits 的組合剛好能產生 16 種不同數值（0000~1111，即十進位 0~15），完美對應 16 進位的 0~F。

1 個 byte＝8 bits＝2 位十六進位數字：byte 的標準大小是 8 個 bits，既然 1 個 16 進位數字只佔 4 bits，就需要 2 個 16 進位數字才能拼湊出一個完整的 byte（4+4=8 bits）。這也是電腦記憶體「最小可定址單位」通常是 1 byte、而該 byte 剛好能用剛好兩位十六進位數字表示的原因。

這一段換算規則跟 [[進位制-二進制-十六進制-Bytes與RGB|進位制筆記]] 第 2 節「為什麼到處是十六進制」完全同一套邏輯，只是這裡是 Python repr() 印記憶體位址這個具體應用場景。
