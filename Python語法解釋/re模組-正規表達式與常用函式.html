重點整理

一、re 模組是什麼

c. re 是 Python 的內建模組（不需要 pip install），用途是處理正規表達式（Regular Expression，簡稱 regex 或正則）——一種用來描述「字串長什麼樣子」的搜尋模式（Pattern）語言。

import re   # 內建，直接 import 就能用

d. 四大應用場景（並列，無先後）：

  • 搜尋與匹配：檢查一段字串裡有沒有符合特定規則的片段。
  • 資料萃取（Extraction）：從一大段文字裡撈出特定格式的資料，例如 email、電話號碼、身分證字號、網址。
  • 字串替換（Substitution）：把符合規則的文字換成別的內容。
  • 字串分割（Splitting）：依據複雜或多變的條件切割字串，補足 str.split() 只能用固定分隔符的限制。

二、五個常用函式（依「找 → 換 → 切」記憶）

e. 找——三個 search 家族的函式，差別在「從哪裡找」與「找幾個」：

函式 從哪裡開始找 找幾個 回傳型別 沒找到時
re.search() 整個字串的任何位置 只找第一個 Match 物件 None
re.match() 只從字串最開頭 只找第一個 Match 物件 None
re.findall() 整個字串 全部 list（串列） [] 空串列 
import re
text = "訂單 A-102 與 A-233 已出貨"

re.search(r"A-\d+", text).group()   # 'A-102'  ← 只回第一個
re.match(r"A-\d+", text)            # None     ← 開頭是「訂」不是 A，所以失敗
re.findall(r"A-\d+", text)          # ['A-102', 'A-233']  ← 全部，且直接是字串串列

f. 最常見的陷阱：把 re.match() 當成 re.search() 用。match() 只錨定字串開頭，中間有再多符合的片段也一律回 None。想在整段文字裡找，請一律用 search() 或 findall()。

g. 第二個陷阱：search() 與 match() 回傳的是 Match 物件而不是字串，要再呼叫 .group() 才拿得到文字；而且沒找到時回的是 None，直接串 .group() 會噴 AttributeError。安全寫法：

m = re.search(r"A-\d+", text)
if m:                 # 先判斷有沒有找到
    print(m.group())

h. 換——re.sub(pattern, 替換成什麼, 原字串)，把所有符合規則的片段換掉：

re.sub(r"\d", "#", "電話 0912-345-678")   # '電話 ####-###-###'

i. 切——re.split()，用規則而非固定字元來切割：

"a1b22c".split("1")            # ['a', 'b22c']   ← 內建 split 只認固定字串
re.split(r"\d+", "a1b22c")     # ['a', 'b', 'c'] ← 連續數字都算一個分隔符

j. 記憶口訣：search 找第一個、match 只認開頭、findall 全都要、sub 負責換、split 負責切。
